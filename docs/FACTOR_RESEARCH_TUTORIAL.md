## 1. 学完后你应该真正会什么

不要把目标定成“能运行脚本”。学完本文后，你应当能够：

1. 用自己的话解释一条因子记录在什么时间可见、预测什么、何时成交。
2. 手算一个动量因子、一个截面标准分和一个 RankIC。
3. 解释本项目怎样处理历史股票池、停牌、ST、涨跌停、复权和交易成本。
4. 从本地真实数据重新生成单因子评价、综合分、目标权重和回测净值。
5. 区分全样本诊断、滚动样本外结果和每日纸面信号，不混用三者。
6. 提出一个有经济含义的因子假设，完成实现、测试、检验、反证和留档。
7. 面对“IC不错但回测不赚钱”时，能从持有期、换手、成本、组合构造和风险暴露中定位原因。

如果你只能说“这个因子收益很好”，却说不清数据时点、标签、股票池和成交规则，就还没有掌握因子研究。

## 3. 因子研究的四个对象

### 3.1 因子 factor

因子是日期 `t` 对股票 `i` 计算出的数值：

\[
f_{i,t}=g(\text{截至 }t\text{ 日可见的信息})
\]

它是一个预测特征，不是收益本身。例如过去中期涨幅、过去波动率、成交额变化。

### 3.2 标签 label

标签是用来评价因子的未来结果。本项目默认未来5个交易日复权收盘收益：

\[
y_{i,t}^{(5)}=\frac{P^{adj}_{i,t+5}}{P^{adj}_{i,t}}-1
\]

标签包含未来信息，只能用于研究评价，绝不能进入日期 `t` 的交易信号。

### 3.3 股票池 universe

股票池回答“日期 `t` 允许比较哪些股票”。当前主线要求：

- 使用当时可见的中证500历史成分快照；
- 至少有120条已观察交易记录；
- 非ST、非停牌；
- 当日成交额至少1000万元；
- ST、停牌、涨跌停状态必须已知。

股票池本身也是数据。如果用今天的500只股票回填十年，会删除已经退市或被调出的失败样本，产生幸存者偏差。

### 3.4 组合 portfolio

因子只给出相对排序，组合把排序变成资金目标。当前主配置是：

- 每周最后一个可用信号日调仓；
- 综合分最高的20只等权；
- 已持有股票跌到第21至30名仍保留，跌出第30名才退出；
- 单股上限5%；
- 信号日收盘后形成计划，下一交易日开盘成交。

研究中必须把“预测是否有效”和“如何交易”分开。相同因子可能因为组合规则不同得到完全不同的净收益。

## 4. 时间轴：防止未来函数的核心

假设今天是交易日 `t`：

```text
t日盘中 ── 不知道完整收盘价、成交额和收盘状态
t日收盘 ── 获得t日OHLCV，计算因子和排名
t日晚间 ── 生成目标权重和纸面计划
t+1开盘 ── 在回测中尝试成交
t+5收盘 ── 此时未来5日标签才完整，只供回看评价
```

本项目在 `run_backtest()` 中用 `_execution_schedule()` 把信号日严格映射到下一个更晚的交易日。测试 `test_signal_executes_next_session_not_same_day` 明确检查：1月2日的信号只能按1月3日开盘价成交。

### 4.1 为什么因子用后复权价，交易用不复权价

- `adj_close`：形成连续收益序列，避免分红送转被误认为暴跌，适合算动量、波动和标签。
- `open/close`：真实价格尺度，适合算股数、100股整手、佣金和现金。

如果用后复权价格计算买入股数，历史价格可能被缩放到不真实水平，现金账本就失去意义。

### 4.2 为什么滚动计算必须先按股票分组

错误写法：

```python
frame["close"].pct_change(20)
```

长表中A股票最后一行后面可能紧跟B股票第一行。上面的代码会把两只股票串起来。

正确模式：

```python
price.groupby(frame["symbol"], sort=False).pct_change(20)
```

项目还会先按 `symbol, trade_date` 排序。测试 `tests/test_factors.py` 用价格尺度相差1000倍的两只股票检查分组结果必须一致。

### 4.3 为什么需要5日隔离带 embargo

若训练窗口最后一个信号日在2020年12月31日，它的5日标签会用到2021年的价格；而2021年可能是验证期。这样训练数据就偷看了验证期。

因此滚动验证会从训练期和验证期末尾各删去5个交易日。隔离带至少应覆盖标签预测长度。

## 5. 当前11个因子到底在算什么

令 `P_t` 为后复权收盘价，`r_t=P_t/P_{t-1}-1`，`A_t` 为成交额，`T_t` 为换手率。

| 因子 | 公式或含义 | 当前配置方向 |
|---|---|---:|
| `momentum_20_5` | `P(t-5)/P(t-20)-1` | +1 |
| `momentum_60_5` | `P(t-5)/P(t-60)-1` | +1 |
| `momentum_120_20` | `P(t-20)/P(t-120)-1` | +1 |
| `reversal_5` | `-[P(t)/P(t-5)-1]` | +1 |
| `reversal_20` | `-[P(t)/P(t-20)-1]` | +1 |
| `volatility_20` | 日收益过去20日标准差，至少15个值 | -1 |
| `volatility_60` | 日收益过去60日标准差，至少40个值 | -1 |
| `amihud_20` | 过去20日 `|r|/成交额` 均值，至少15个值 | -1 |
| `turnover_mean_20` | 过去20日平均换手率，至少15个值 | -1 |
| `amount_momentum_20` | 5日平均成交额/20日平均成交额-1 | +1 |
| `price_volume_corr_20` | 日收益与 `Δlog(成交额)` 的20日相关系数 | +1 |

### 5.1 动量为什么跳过最近几天

`momentum_60_5` 观察第60日至第5日前的涨幅，跳过最近5日。它尝试把中期趋势和非常短期反转分开。跳过期不是必然真理，而是事先提出的研究假设。

### 5.2 反转因子为什么前面有负号

过去涨得越多，短期回撤假设越强。原始5日收益高时，`reversal_5` 变得更低；因此“反转更强”的股票有更高因子值。

### 5.3 `direction` 与因子公式不是一回事

配置中的 `direction` 是合成时的方向约定：

```text
用于综合分的单因子分数 = factor_processed × direction
```

这里有一个很容易踩坑的输出口径：

- `factor_summary.csv` 的 `mean_ic` 是乘方向前的原始处理因子 IC；
- `oriented_mean_ic` 才是 `mean_ic × configured_direction`；
- `factor_scores.parquet` 中11个以因子名命名的列已经乘过方向；
- 滚动样本外筛选使用的是这些已经调整方向的列。

不能看到全样本 `mean_ic` 为负，就事后把方向改成负数并宣称成功。方向应来自经济假设，或者只在训练窗口决定，然后冻结到验证期和测试期。

### 5.4 因子值不是跨日期直接可比的

今天的 `2.0` 和明天的 `2.0` 都表示各自当日截面大约高于均值两个标准差，不意味着绝对经济量相同。本项目主要做每日横截面选股，而不是把因子绝对水平跨年比较。

## 6. 从原始因子到可比较分数

### 6.1 第一步：按日MAD去极值

对日期 `t` 的全部有效股票，先求中位数：

\[
m_t=\operatorname{median}(f_{i,t})
\]

再求中位绝对偏差：

\[
MAD_t=\operatorname{median}(|f_{i,t}-m_t|)
\]

项目用 `1.4826 × MAD` 近似正态分布标准差，并把数值截在：

\[
[m_t-5\times1.4826MAD_t,\ m_t+5\times1.4826MAD_t]
\]

这样做不是删除异常股票，而是减少极端值对均值和标准差的支配。

### 6.2 第二步：按日Z-score

\[
z_{i,t}=\frac{f^{winsor}_{i,t}-\bar f_t}{\sigma_t}
\]

处理后，每个有效截面的均值接近0、标准差接近1。不同量纲的动量、波动率和流动性因子才可以合成。

### 6.3 第三步：可选中性化

若有严格时点市值和历史行业，可以每天做横截面回归：

\[
z_{i,t}=\alpha_t+\beta_t\log(Size_{i,t})+
\sum_k\gamma_{k,t}Industry_{i,k,t}+\epsilon_{i,t}
\]

残差 `ε` 是剔除规模和行业解释后的因子。残差还会再次标准化。

当前配置关闭市值和行业中性化，因为免费数据没有足够可靠的历史时点字段。缺数据时强行中性化，比明确关闭更危险。

### 6.4 第四步：覆盖率门槛

每天在可交易股票池内计算：

\[
Coverage_t=\frac{\text{当日有有效因子值的股票数}}
{\text{当日股票池股票数}}
\]

当前单因子最低覆盖率为80%。低于门槛时，该因子当天整截面作废。综合分至少需要11个因子中的8个有效。

### 6.5 第五步：等权综合

先乘预设方向，再对可用因子取平均：

\[
C^{raw}_{i,t}=\frac{1}{K_{i,t}}
\sum_{k\in available} direction_k\cdot z_{i,t,k}
\]

最后再对每日综合分做一次Z-score，得到 `factor_processed`。这个字段是组合排名直接使用的综合因子。

## 7. 因子检验：不要一上来只看净值

一条合格的因子研究证据链应按以下顺序检查：

```text
数据和覆盖率
→ 因子分布与异常值
→ RankIC及时间稳定性
→ 分组单调性
→ 与已有因子的相关性
→ 信号稳定性和换手
→ 样本外组合
→ 成本后结果与基准
```

### 7.1 RankIC

每天在股票横截面计算因子排名与未来收益排名的 Spearman 相关系数：

\[
RankIC_t=Corr(Rank(f_{i,t}),Rank(y_{i,t}^{(5)}))
\]

- 正值：因子越高，未来收益排名倾向越高；
- 负值：因子越高，未来收益排名倾向越低；
- 接近0：当天几乎没有截面排序信息。

用排名相关而非普通相关，可以降低极端收益和非线性尺度的影响。

### 7.2 平均IC、胜率与ICIR

\[
\overline{IC}=\frac{1}{T}\sum_t IC_t
\]

\[
WinRate=\frac{\#\{IC_t>0\}}{T}
\]

本项目5日标签下使用：

\[
ICIR=\frac{mean(IC)}{std(IC)}\sqrt{252/5}
\]

注意：每天计算的5日未来收益彼此重叠，IC序列存在自相关。`sqrt(252/5)` 是当前项目明确采用的近似年化口径，不等同于严格的独立同分布推断。做论文级统计检验时，应进一步使用非重叠样本、Newey-West 或块状Bootstrap。

### 7.3 五分组收益

每天按因子从低到高分成5组，计算各组未来5日等权平均收益。理想状态不仅是第五组高于第一组，还应大致单调：

```text
Q1 < Q2 < Q3 < Q4 < Q5
```

如果只有Q5突出、中间组杂乱，可能是尾部效应；如果多空差只来自Q1暴跌，做多策略未必能获得同样收益。

### 7.4 因子相关性

项目每天计算各因子的截面 Spearman 相关，再跨日期平均。高相关因子可能重复计票。

例如20日和60日波动率通常有明显相关性。把两个高度相关因子等权加入，不代表获得两份独立信息，而可能只是把“低波动”权重放大。

### 7.5 稳定性

`factor_stability.csv` 给出逐年以及近期63/126/252/756/1260交易日窗口的均值IC和胜率。你要问：

- 符号是否跨年份稳定？
- 效果是否只集中在某个市场阶段？
- 最近一年是否衰减？
- 观察数是否足够？

### 7.6 信号换手

预测每天变化过快，即使IC高，也可能被成本吞噬。换手必须与预测周期一起看：5日标签配周频调仓相对一致；若改成月频，成本下降，但目标持有期和标签不再完全一致。

## 8. 滚动样本外验证是怎么工作的

全样本IC可以用来理解数据，但不能证明未来有效。当前滚动方案是：

- 训练5年；
- 验证1年；
- 测试1年；
- 每次向前移动1年；
- 训练和验证末尾各留5个交易日隔离带。

以第一折为例：

```text
2016—2020：训练，末尾删5个交易日
2021：验证，末尾删5个交易日
2022：完全样本外测试
```

下一折变成：

```text
2017—2021：训练
2022：验证
2023：测试
```

### 8.1 当前普通因子的筛选规则

每一折对已经按配置方向调整过的单因子计算训练IC和验证IC：

```text
训练IC > 0 且 验证IC > 0 → 入选
否则 → 该折不用这个因子
```

入选因子的权重与验证期IC成比例。权重一旦确定，只用于随后测试年，不根据测试结果回头调整。

### 8.2 滚动验证能防什么，不能防什么

能降低：

- 用测试期选择因子；
- 用全样本决定权重；
- 标签跨越训练/验证边界；
- 单次切分碰巧有利。

不能自动消除：

- 研究者反复尝试几十个因子后只保留最好结果；
- 数据源本身的幸存者偏差或时点错误；
- 交易成本和成交模型过于乐观；
- 因子背后的经济机制已经失效；
- 同一批测试年份被人为看过太多次。

测试集也是会被“用旧”的。每次看完结果再修改假设，下一次实验就不再是真正盲测。

## 9. 从分数到持仓：Top N与退出缓冲

每个调仓信号日按 `factor_processed` 从高到低排序。

### 9.1 首次建仓

选择前20只，每只目标权重5%。若有效股票不足20只，单股仍不超过5%，剩余资金留现金。

### 9.2 后续调仓

假设原持仓A从第18名掉到第25名：

- 它已不在Top 20；
- 但仍在Rank 30以内；
- 因此继续持有，减少无意义换手。

只有跌出第30名才优先退出，再从高排名股票补足20只。

### 9.3 调仓日期

`W-FRI` 的含义是每个自然周最后一个实际观察到的交易日，不保证一定是星期五。遇到周五休市，可能选择周四。

最新一天与下一个交易日在同一自然周时，代码不会把最新日误认为已经完成的周末调仓边界，因此每日有排名，不代表每天有订单。

## 10. 回测引擎逐步拆解

### 10.1 每个交易日发生什么

1. 检查当天是否有前一信号日待执行的目标。
2. 用开盘价计算调仓前总资产。
3. 先卖出，释放现金。
4. 再买入，现金不足时按100股逐手减少。
5. 收盘用不复权收盘价计算持仓市值。
6. 记录现金、持仓市值和总权益。

### 10.2 成交价格

设滑点为 `s=5/10000`：

\[
BuyPrice=Open\times(1+s)
\]

\[
SellPrice=Open\times(1-s)
\]

这是简化的固定滑点模型，不等于真实冲击成本。

### 10.3 股数和整手

\[
DesiredShares=\left\lfloor
\frac{TargetValue}{Open\times100}
\right\rfloor\times100
\]

A股普通股票按100股整数手处理。目标权重与实际权重会因价格和现金约束有偏差。

### 10.4 费用

买卖佣金：

\[
Commission=\max(5, Gross\times0.0003)
\]

另收参数化过户费 `Gross × 0.00001`。卖出还收印花税：

- 2023-08-28以前：0.1%；
- 2023-08-28起：0.05%。

印花税只在卖出侧收取。代码按交易日期选择历史税率。

### 10.5 交易约束

- 停牌：不能买，也不能卖；
- 涨停：不能买；
- 跌停：不能卖；
- 卖不掉的股票继续留在账上，不能因为目标权重为0就凭空消失。

### 10.6 当前回测仍有哪些近似

- 未逐笔模拟分红送转现金流；
- 未模拟集合竞价排队和封板打开过程；
- 固定滑点没有随成交额、订单规模和市场波动变化；
- 没有容量模型；
- 中证500成分快照按周采样，调整日附近可能有少量时点误差；
- 诊断基准是历史成分股每日等权、无成本，不是官方中证500指数复制。

因此回测是研究近似，不是券商对账单。

## 11. 绩效指标怎么读

### 11.1 总收益与年化收益

\[
TotalReturn=\frac{NAV_T}{NAV_0}-1
\]

\[
AnnualReturn=(1+TotalReturn)^{1/Years}-1
\]

### 11.2 年化波动和Sharpe

\[
AnnualVol=Std(r_{daily})\sqrt{252}
\]

当前项目未扣无风险利率：

\[
Sharpe=\frac{Mean(r_{daily})}{Std(r_{daily})}\sqrt{252}
\]

### 11.3 最大回撤

\[
Drawdown_t=\frac{NAV_t}{\max_{s\le t}NAV_s}-1
\]

最大回撤是整个序列中最负的回撤值。它描述历史最深亏损，不代表未来上限。

### 11.4 Calmar

\[
Calmar=\frac{AnnualReturn}{|MaxDrawdown|}
\]

### 11.5 本项目换手口径

\[
Turnover=\frac{\sum |TradeGross|/2}{AverageEquity}
\]

这是全回测期累计口径，不是自动年化值。比较不同长度实验前，要先统一样本期。

数据截止2026-09-16，正式研究从2016-01-01开始，2015年只作预热。

### 14.1 全样本诊断

- 综合因子平均RankIC约 `0.0286`；
- ICIR约 `1.22`；
- IC胜率约 `59.38%`；
- 含成本组合年化约 `-6.21%`；
- 最大回撤约 `-59.07%`；
- 同期无成本诊断基准年化约 `2.84%`。

全样本组合明显失败。不能只引用正IC而隐藏负收益。

### 14.2 滚动样本外

样本外区间2022-01-04至2026-09-16，共5折：

- 平均RankIC约 `0.0663`；
- ICIR约 `2.05`；
- IC胜率约 `61.44%`；
- 含成本组合年化约 `0.01%`；
- 最大回撤约 `-30.24%`；
- 同期诊断基准年化约 `3.66%`；
- 策略年化落后基准约 `3.65` 个百分点。

### 14.3 为什么排序能力没有转化成收益

这是当前项目最值得学习的问题，可能来源包括：

1. **标签与组合不完全一致**：IC评价未来5日收盘收益，组合却在下一日开盘成交，并受周频持有和退出缓冲影响。
2. **成本与换手**：小的排序优势经过频繁换仓后可能不够覆盖摩擦。
3. **头部不等于全截面**：RankIC利用全部股票，Top 20可能没有同样稳定的优势。
4. **风险暴露**：因子可能隐含风格或行业暴露，当前又缺少可靠时点数据做中性化。
5. **等权合成稀释**：无效或方向错误的因子会稀释有效信号。
6. **可成交约束**：理论排名变化不一定能在涨跌停、停牌和整手限制下实现。

正确结论不是“因子一定无效”，也不是“IC高所以可以实盘”，而是：当前排序信息尚未在这套可执行组合规则下形成稳定超额收益。

### 15.2 实现因子

在 `src/quant_lab/factors/library.py` 中加入：

```python
def downside_volatility_20(frame: pd.DataFrame) -> pd.Series:
    """20-day volatility of negative adjusted daily returns."""
    require_columns(frame, ["symbol", "close"])
    price = _adjusted_close(frame)
    returns = price.groupby(frame["symbol"], sort=False).pct_change()
    downside = returns.clip(upper=0.0)
    return (
        downside.groupby(frame["symbol"], sort=False)
        .rolling(20, min_periods=15)
        .std()
        .reset_index(level=0, drop=True)
    )
```

然后注册：

```python
FACTOR_REGISTRY = {
    # existing factors...
    "downside_volatility_20": downside_volatility_20,
}
```

- 是否只用了当日及过去数据？
- 是否按 `symbol` 分组？
- 输入是否先排序？

## 16. 怎样产生值得研究的因子想法

不要从“枚举100个窗口”开始。先从机制出发。

### 16.1 趋势与反转

问题：价格变化是在延续，还是短期过度反应？

可研究：

- 不同跳过期的中期动量；
- 隔夜收益与日内收益拆分；
- 高成交量确认后的趋势；
- 极端下跌后的短期反转。

### 16.2 风险与波动

问题：投资者是否要求高风险补偿，还是偏好彩票型股票？

可研究：

- 下行波动率；
- 收益偏度；
- 最大单日涨幅；
- 特质波动率。

项目已预留 `ivol_60`，但它用截面等权市场收益近似市场因子，应先理解近似边界再启用。

### 16.3 流动性与交易拥挤

问题：交易困难、成交突然放大或高换手是否获得补偿或代表拥挤？

可研究：

- Amihud非流动性；
- 成交额冲击后的收益延续/反转；
- 换手率变化而非换手率水平；
- 零成交或停牌频率。

### 16.4 价量关系

问题：上涨是否得到成交量确认？

可研究：

- 收益与成交额变化相关性；
- 上涨日成交额/下跌日成交额比；
- 价格创新高但成交额未创新高的背离。

### 16.5 基本面和估值

项目已有 `book_to_price` 和 `earnings_yield` 函数，但当前免费主数据没有可靠时点财务字段，不能直接启用。

基本面数据必须按公告日对齐。例如2025年年报即使报告期是2025-12-31，也不能在年末提前使用；只能在实际披露后进入信号。

## 17. 防止把过拟合当成挖因子

### 17.1 一次只改变一个主要假设

同时改窗口、股票池、调仓频率、成本和持仓数，结果变好后无法知道原因。

建议实验命名：

```text
EXP-001_downside-vol-20_single-factor
EXP-002_downside-vol-20_add-to-baseline
EXP-003_downside-vol-20_top50
```

### 17.2 参数网格要事先声明

例如只比较 `[10, 20, 60]` 三个窗口，并在运行前写入实验卡。不要跑完后只展示最好的17日窗口。

### 17.3 经济意义优先于小数点优势

`IC=0.031` 不必然优于 `IC=0.029`。还要看跨期稳定性、相关性、覆盖率、换手、成本和解释性。

### 17.4 多重检验

如果随机测试100个无效因子，也可能出现几个漂亮结果。候选越多，越需要：

- 保留所有尝试；
- 使用滚动样本外；
- 留最后一段真正未观察数据；
- 对相似因子按“一个家族”而非100个独立发现计数；
- 必要时使用Deflated Sharpe、White Reality Check等更严格工具。

这些高级统计工具尚未集成本项目，不能假装已经解决多重检验。

### 17.5 不要把测试集调成训练集

看完2022—2026样本外结果后根据它改公式，再次查看同一区间，这段数据事实上已经参与研究决策。应在实验记录中把它标为“已观察”。

## 18. 常见错误与定位方法

### 错误1：因子前几个月全是NaN

先看最长窗口和上市时间。120日动量需要足够历史，股票池还要求120个观察交易日。这可能是合理预热，不一定是程序错误。

### 错误2：覆盖率突然大幅下降

检查：

- 原始行情某日是否缺失；
- 成交额是否被错误缩放；
- 状态已知字段是否丢失；
- 新因子是否对0取对数或除以0；
- rolling的 `min_periods` 是否太严格。

### 错误3：IC异常接近1

优先怀疑未来函数：

- 是否把 `shift(-5)` 的未来价格放进特征；
- 是否在全样本上做了带未来信息的填充；
- 是否把标签列误当成因子；
- 是否用测试期决定方向或权重。

### 错误4：IC为正但Top组合差

检查头部分组、开盘到收盘差异、换手、成本、缓冲、集中度和风格暴露，而不是立即换模型。

### 错误5：回测交易发生在信号当天

这是严重未来函数。检查 `trades.csv` 的 `signal_date` 与 `trade_date`，后者必须严格更晚。

### 错误6：收益好得不现实

把成本调高、延迟成交、扩大持仓数、检查涨跌停和复权跳点。异常优秀通常先视为数据或对齐问题，直到证据排除这些可能。

### 错误7：改了配置但结果没变化

检查运行命令的 `--config`、输出目录中的 `effective_config.yaml`，以及是否误读了旧输出目录。

### 错误8：单因子方向看起来“写反了”

同时检查 `mean_ic`、`configured_direction` 和 `oriented_mean_ic`。不要只看原始IC列。

## 19. 推荐的45分钟学习路线

每课都按“5分钟回忆、30分钟实践、10分钟闭卷复述”进行。

### 第1课：画出时间轴

- 目标：分清特征、标签、信号和成交。
- 实践：从 `factor_scores.parquet` 选一只股票和一个日期，找出 `t`、`t+1`、`t+5`。
- 交付物：一张手画时间轴。
- 验收：能解释为什么不能在 `t` 日收盘价成交。

### 第2课：手算动量

- 目标：理解分组shift。
- 实践：找一只股票连续65日后复权收盘价，手算 `momentum_60_5`。
- 交付物：公式、代入数字、与程序值对照。
- 验收：误差来自浮点数，而不是日期错位。

### 第3课：手算截面处理

- 目标：理解去极值和标准化。
- 实践：构造6只股票，其中一只极端值，手算中位数、MAD、截断和Z-score。
- 交付物：一张小表。
- 验收：能解释为何不是沿单只股票时间序列标准化。

### 第4课：手算RankIC

- 目标：理解横截面排序预测。
- 实践：用5只股票因子值和未来收益排名计算Spearman相关。
- 交付物：排名表和相关系数。
- 验收：能说明RankIC与策略日收益不是同一个量。

### 第5课：阅读单因子结果

- 目标：不只看平均IC。
- 实践：从当前11个因子选两个，比较IC、胜率、年度稳定性、覆盖率和相关性。
- 交付物：200字比较结论。
- 验收：至少写出一个失效证据。

### 第6课：从排名到目标权重

- 目标：理解Top 20和Rank 30缓冲。
- 实践：用30只虚拟股票连续两周排名，手工生成持仓变化。
- 交付物：两期持仓表。
- 验收：第25名旧持仓不会被错误卖出。

### 第7课：复核一笔交易

- 目标：理解下一开盘、费用和整手。
- 实践：从 `trades.csv` 随机取一笔交易，反算毛额、佣金和税。
- 交付物：计算过程。
- 验收：买入无印花税，卖出税率与日期匹配。

### 第8课：理解样本外折

- 目标：理解训练、验证、测试和隔离带。
- 实践：从 `walk_forward/fold_summary.csv` 画出5折时间轴。
- 交付物：每折年份和入选因子表。
- 验收：测试年没有参与该折因子选择。

### 第9课：解释当前负结果

- 目标：建立诚实研究表达。
- 实践：同时读样本外IC、交易、权益和基准。
- 交付物：不超过300字的研究结论。
- 验收：不能写“IC高，所以策略有效”；必须提成本后收益和基准。

### 第10课：实现一个新因子

- 目标：完成假设—代码—测试闭环。
- 实践：实现本文的 `downside_volatility_20`。
- 交付物：函数、注册项、至少两个测试。
- 验收：测试通过，未来价格变化不影响过去因子。

### 第11课：完成单因子报告

- 目标：判断新因子是否值得保留。
- 实践：独立配置、独立输出目录、完整运行。
- 交付物：假设、结果、反证、结论四段式报告。
- 验收：包含失败可能性和与已有波动因子的相关性。

### 第12课：做一次可复现讲述

- 目标：达到项目/面试表达标准。
- 实践：不看代码，10分钟讲清数据、因子、检验、回测和局限。
- 交付物：录音或文字稿。
- 验收：另一位同学能按你的说明复现同一结果。
