行业、市值中性化的练习仅可用合成数据，目前真实财务与行业口径尚未验收。

## 可运行练习：收盘位置 → 完整实验

问题：近20天更常在日内高位收盘的股票，未来5日收益排名是否较高？这是待检验假设。
某日高12元、低10元、收11.5元，位置为 `(11.5-10)/(12-10)=0.75`。
把每天的位置取过去20个交易日均值；只使用当天收盘已经可见的信息。

现成代码：`src/quant_lab/factors/custom/range_position_20.py`。
输入 `adj_high/adj_low/adj_close`；输出与原表对齐的 Series；最少20日历史。

1. 在网页“运行因子研究”选择合成演示，点击“更新代码因子”，确认该因子通过校验。
2. 选择 `range_position_20`，并集，2016-01-01至2024-12-18，启动研究并打开成功报告。
3. 阅读因子诊断，先写下覆盖率、分层是否有序、年度IC是否稳定；不因结果差翻方向。
4. 策略设置5,000元、5只、退出30、周频、单股20%，费用保持默认。
5. 填写上述假设，勾选Walk-forward和单因素对照，运行。
6. 实验历史记录实际持仓、现金和未成交原因。保存“支持/不支持/证据不足”的结论。
7. 载入参数，只改初始资金为10,000，再运行，比较两个实验。解释差异是否来自整数股和费用。
8. 导出配置和报告。真实数据可重复同一路线，但先检查授权、来源、历史股票池和截止日。

验收：重新打开网页仍能找到实验；能够独立解释分组滚动、下一交易日成交、
实际持股数、至少一个样本外测试区间和两个模型局限。合成数据练习不是因子有效性证据。
