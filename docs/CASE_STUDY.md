# 研究案例：A股普通价量因子闭环

## 问题与目标

目标不是展示一条被挑选出来的高收益曲线，而是搭建可复现的日频研究流程：收盘后增量
获取免费真实数据，检查完整性，以当日可见信息生成因子，并将目标组合安排到下一交易日
开盘执行。

## 数据与时点

- 数据源：BaoStock免费日线。
- 股票池：历史时点中证500周度快照；周内使用最近一次已知名单。
- 验收样本：2015-01-05至2026-09-09，1,357只历年成员、2,841个交易日、
  3,375,198行。2015年作为因子预热期，正式评价从2016年开始。
- 价格口径：后复权价用于因子和标签，不复权价用于成交、股数和费用。
- 交易时点：第`t`日收盘形成信号，第`t+1`个交易日开盘模拟成交。

真实行情及账户状态不进入Git仓库，使用者需要自行运行增量下载流程。

## 因子与验证

系统批量评价11个普通价量因子，包括多周期动量、短期反转、波动率、Amihud非流动性、
换手、成交额变化和价量相关性。每个因子经过MAD去极值和截面标准化；覆盖不足80%的
交易日不使用该因子，每只股票至少有8个有效因子才生成固定方向综合分。

正式样本外流程采用5年训练、1年验证、1年测试并逐年滚动，标签末端隔离5个交易日。
每折只根据过去训练期和验证期的RankIC选择因子、确定权重，再对下一年评分。2022至
2026共形成5个样本外折。

默认组合为周频调仓、Top 20、Rank 30退出缓冲，并模拟佣金、按历史日期变化的印花税、
过户费、滑点、最低佣金和100股整手约束。每天仍计算排名；非调仓日输出`NO_TRADE`。

## 当前结果与解释

全期固定方向综合分的未来5日平均RankIC约0.0286；因为包含样本内区间，只能作为因子
诊断。更重要的滚动样本外结果为：平均RankIC约0.0662、ICIR约2.05、胜率约61.27%。
五个测试年的平均RankIC分别约为0.0776、0.0886、0.0907、0.0123和0.0600，2025年
明显衰减，说明因子有效性并不稳定。

排序能力没有直接转化成可观的组合收益。样本外组合总收益约1.11%，年化约0.24%，
Sharpe约0.11，最大回撤约-30.24%。因此当前结论是：研究链路和样本外检验成立，存在
一定截面排序信号，但当前Top 20周频组合远未达到可实盘标准。下一步应研究风险暴露、
换手成本、分层单调性和组合构建，而不是把低收益结果包装成稳定Alpha。

## 已知限制

1. 历史指数成分按周采样，指数调整生效日附近可能有少量时点误差。
2. 免费数据缺少严格历史行业和时点市值，当前不宣称完成行业/市值中性化。
3. 28个绝对复权日收益超过25%的观察值仍需结合公司行动和公告抽查。
4. 尚未逐笔建模分红送转现金流、集合竞价排队、容量和冲击成本。
5. 输出是研究与纸面复核材料，不是自动实盘交易指令。
