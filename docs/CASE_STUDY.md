# 研究案例：A股普通价量因子闭环

## 问题与目标

目标不是展示一条被挑选出来的高收益曲线，而是搭建可复现的日频研究流程：收盘后增量
获取免费真实数据，检查完整性，以当日可见信息生成因子，并将目标组合安排到下一交易日
开盘执行。

## 数据与时点

- 数据源：BaoStock免费日线。
- 股票池：当前中证500成分，并从首次运行起保存本地时点快照。
- 验收样本：500只股票，2024-07-01至2026-09-08，共264,800行、534个交易日。
- 价格口径：后复权价用于因子和标签，不复权价用于成交、股数和费用。
- 交易时点：第`t`日收盘形成信号，第`t+1`个交易日开盘模拟成交。

真实行情及账户状态不进入Git仓库，使用者需要自行运行增量下载流程。

## 因子与组合

系统批量评价11个普通价量因子，包括多周期动量、短期反转、波动率、Amihud非流动性、
换手、成交额变化和价量相关性。每个因子依次经过MAD去极值、截面标准化、RankIC、
ICIR和分层收益检查；综合分采用配置中预先声明的方向，避免根据回测结果事后翻转符号。

默认组合为周频调仓、Top 20等权、Rank 30退出缓冲，并模拟佣金、印花税、过户费、
滑点、最低佣金和100股整手约束。每天仍然计算最新排名；非调仓日明确输出
`NO_TRADE`。

## 当前结果与解释

截至2026-09-08，11因子等权综合分的平均未来5日RankIC约为-0.0077，ICIR约为
-0.358，胜率约为49.5%。研究期组合年化收益约4.32%，Sharpe约0.32，最大回撤约
-14.50%。这些结果没有证明稳定Alpha，因此项目不会把正的累计收益包装成策略有效性。

这个负结果说明下一步应先检查因子方向的跨期稳定性、降低高度相关暴露、做真正的滚动
样本外验证，再考虑机器学习模型。工程闭环已经成立，预测能力仍待改进。

## 已知限制

1. 首份中证500快照之前使用当前成员回填，存在幸存者偏差。
2. 免费数据缺少严格历史行业和时点市值，当前不宣称完成行业/市值中性化。
3. 尚未逐笔建模分红送转现金流、集合竞价排队、容量和冲击成本。
4. 输出是研究与纸面复核材料，不是自动实盘交易指令。
