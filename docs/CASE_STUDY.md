# 研究案例：从可检验假设到可复现结果

公开案例只展示合成数据生成的材料：[演示报告](../examples/synthetic_demo/README.md)。
原有真实数据研究记录已保存在本机归档和修改前的代码文档恢复包中，不能把旧版本业绩当成新版本结果。

研究问题：过去20日收盘更靠近日内高点的股票，未来5日排名是否更高？
这是假设，不预先承诺收益。因子实现为 `range_position_20.py`，输入调整后的高、低、收盘价。

流程：声明字段与20日预热 → 历史股票池截面标准化 → 覆盖、RankIC、分层、年度检验 →
5,000元小资金、Top5、退出30、周频、20%单股上限 → 下一交易日开盘成交 →
固定参数5+1+1验证 → 持仓数/频率/双倍成本对照 → 保存全部结果及失败原因。

复现请按 [使用教程](USER_GUIDE.md) 与 [小白练习](BEGINNER_COURSE.md)。
网页验收脚本 `scripts/verify_dashboard_flow.py` 会实际操作表单、启动后台进程、
保存并重开实验，载入参数改为10,000元，再核对成交明细确实发生变化。
它使用合成数据，不下载付费数据，不改模拟账户。

研究结论必须区分：代码正常运行、某个样本里的统计相关、扣费后组合表现、未观察过的样本外证据。
合成样本只能支持第一项。真实数据实验同样必须保留失败结果，并披露历史成员快照缺口、
交易状态未知、公司行动账本近似及账户准入等限制。
