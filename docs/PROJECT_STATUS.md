## 仍然存在的边界

1. BaoStock历史成分按周采样，周内沿用最近已知截面；指数调整生效日附近可能有少量
   时点误差。
2. BaoStock免费字段没有严格历史行业和时点市值，因此当前关闭行业/市值中性化。
3. 回测尚未逐笔模拟分红送转现金流、集合竞价排队、容量和冲击成本。
4. 28个极端复权收益观察值需要结合公告抽查，不能直接视为真实可交易收益。
5. MLP代码框架已具备验证集早停、最佳权重恢复和检查点；已安装并验证
   `torch 2.6.0+cu124`、RTX 3060 CUDA运算及MLP单元测试，但尚未形成完整真实数据
   滚动结果。在Ridge/LightGBM成本后均未胜出前，不把深度模型结果用于每日信号。
6. 第二数据源核验仍待后续；GitHub不包含原始行情、Token或账户状态。
