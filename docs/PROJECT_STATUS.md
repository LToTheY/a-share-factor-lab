## 已实现

- 国泰安优先、BaoStock补齐的正式日线库；历史沪深300、中证500和并集共享行情。
- 网页与命令行共用研究服务，按因子声明读取字段和预热历史，每个股票池重新截面处理。
- 单重型任务、去重、落盘状态、日志、协作式取消、失败隔离和版本绑定。
- 自定义因子 → 诊断 → 策略参数 → 小资金账本 → 当前策略的Walk-forward → 全部单因素对照。
- 实验保存、重开、参数载入、结论记录、差异比较、配置及报告导出。
- 报告因子等权、模块内/模块间等权与可编辑权重；按排名或按预算选择候选。
- 次日开盘标签、标签覆盖率、年度IC与HAC区间；目标持仓、实际持仓及未成交原因分开记录。
- 从自己的已保存策略生成每日人工复核清单，绑定策略、代码、数据和本机账户快照。
- 研究任务保留运行依赖版本与去重的源码快照；旧结果缺少源码时明确说明。
- 本地批量研究档案展示全部预设案例、失败和未完成项，不按收益自动选策略。
- 实验历史可独立核对现金、成交、每日股数与净值；检查失败时列出具体不一致项。
- 无账号合成演示与教程；真实数据、账户、日志、恢复包和衍生明细只留在本机。

## 数据与容量

正式库在 `data/processed/market_daily.parquet`，原验收截止2026-09-29，共3,944,905行、
1,579只历史股票，单文件约267 MB。CSMAR行情实际到2024年底，其后由BaoStock补充。
当期检查先联网更新近期窗口；全历史重建为独立入口，详见 [DATA_USAGE](DATA_USAGE.md)。
2026-09-30 03:19测量：data约1.77 GB、reports约2.94 GB，合计约4.71 GB，
虚拟环境另约5.60 GB。本次持续改进开始时data与reports合计约2.59 GB；新增约2.12 GB，
主要来自保留的多版本全历史研究、预设对照与验收产物。原始行情和原模拟账户哈希未变。
部分不可变报告做了NTFS透明压缩，文件逐一验哈希不变，节省实际分配空间约47 MB。
最新验收与容量记录见本机 `data/state/`；每次实验会新增结果文件。

## 保留的限制

- 财报、市值、历史行业未验收；分钟、深度学习和自动实盘不属于当前主线。
- 历史成员按已知快照沿用；499只不完整快照、异常金额及未知交易状态不做猜测补齐。
- 分红送转、退市清算、冲击与队列未完整建模；缺失持仓估值会明确记录，不能声称精确实盘收益。
- 因子研究报告保留原来的训练/验证选因子流程；策略实验采用用户预先固定的权重和规则，
  两种验证在页面上区分，不能互相代替。看到测试结果后再调参属于再次探索。
- 旧ML模块和历史研究记录保留作参考，本轮没有重跑其真实数据业绩。
