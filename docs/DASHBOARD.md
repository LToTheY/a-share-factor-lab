# 本地因子研究看板

这个看板把 `reports/generated/daily_factor_lab/` 中已有的研究产物展示在网页上。
研究报告以只读方式展示；因子库可保存本地档案，策略实验室可运行隔离实验。
看板不修改模拟账户，也不发送真实交易指令。
“今日调仓检查”可由用户点击启动本地更新，显示最新日行情核验及纸面建议。

新增一键后台研究、小资金实验、实验自己的样本外验证及网页内教程。完整操作见 [使用教程](USER_GUIDE.md)。
已安装环境可双击项目根目录`start_dashboard.cmd`；新增自己的策略每日复核、全部批量研究档案及独立账本核对。

## 1. 安装

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dashboard]"
```

如果已经安装完整环境 `.[all]`，不需要重复安装。

## 2. 准备研究结果

日常判断是否需要调仓，可直接在“今日调仓检查”点击更新，或执行：

```powershell
.\scripts\daily_update.ps1
```

该入口不重做完整历史回测。历史研究页读取之前保存的报告；需要重建时使用
`scripts/run_factor_suite.py`，它只读现有历史数据，不能据此声称数据已更新。
如果只是验证代码，可按项目测试和合成数据说明生成测试结果；不能把合成数据表现解释成真实策略业绩。

## 3. 启动

```powershell
.\scripts\run_dashboard.ps1
```

也可以直接运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run dashboard\app.py
```

浏览器通常会自动打开 `http://localhost:8501`。停止服务时在运行窗口按 `Ctrl+C`。

## 4. 页面说明

- **因子库**：按频率浏览、搜索和分类筛选因子，保存或编辑研究档案。
- **日频因子**：展示计算库中的内置因子，有研究报告时可直接跳转到对应诊断。
- **日内因子**：提供 1/5/15/30/60 分钟及 Tick 档案入口，尚未接入计算与回测。
- **其他频率**：提供周频、月频、事件档案入口，尚未接入计算与回测。
- **系统总览（默认首页）**：先检查数据日期、审计状态、研究边界和最新排名。
- **今日调仓检查**：一键更新、检查当前数据完整性、显示最新因子排名及纸面建议；
  更新失败、数据过期、配置/持仓改变时隐藏上一轮建议。下载与历史补齐共用进程锁。
- **因子研究**：查看单因子 IC、年度稳定性、截面分布和因子相关性。
- **策略实验室**：组合因子，修改持仓、调仓与成本参数，在隔离沙盒中运行回测。
- **回测分析**：比较策略与基准，检查回撤、换手、交易和持仓。
- **实验历史**：查看本地自动保存的回测，比较参数及绩效，按交易日回放目标、成交、持仓和执行受阻原因。
- **现金、成交与持仓对账**：在实验历史中点击核对，从保存的成交独立检查现金、股数和净值；不替代数据及公司行动核验。
- **我的策略每日复核**：复用已保存的真实策略和自己填写的账户快照，更新行情后查看人工清单。
- **批量研究档案**：按预先声明的顺序显示全部案例、失败和未完成项。
- **样本外检验**：检查 Walk-forward 各折选择和 OOS 表现。
- **方法与课程**：将页面指标对应到 `docs/factor_course/` 的课程。
- 教程中的文档链接与合成演示图表可在网页内阅读；图表明确标注为合成数据。

## 5. 性能和数据边界

- 小型 CSV/JSON 根据文件修改时间缓存。
- 大型 `factor_scores.parquet` 使用 DuckDB，只读取所选因子和最新截面。
- 页面不公开本地路径选择器；研究档案不会修改正式研究配置或执行用户填写的公式。
- 自定义档案存储于 `data/state/factor_catalog.sqlite3`（默认被 Git 忽略），
  支持 JSON 导出备份。标识在同一频率、同一采样周期下唯一；不同周期可以同名。
- 档案保存不代表因子已实现或通过验证。新因子需另行实现计算、测试和研究接入。
- 因子采样频率与策略调仓频率分开：日频因子可以配合周频调仓使用。
- `reports/generated/` 默认不提交 Git；公开部署前必须单独设计脱敏示例数据或私有存储。

## 6. 故障排查

### 页面提示缺少研究文件

历史页需确认 `reports/generated/daily_factor_lab/summary.json` 等文件存在；
“今日调仓检查”不依赖该历史报告，可单独更新并运行。

### `No module named streamlit`

重新执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dashboard]"
```

### 页面数字和报告不一致

先确认数据截止日是否一致，然后比较 `summary.json`。看板不自行重算指标；若仍不一致，属于产物读取或展示错误，应停止使用并运行测试。
