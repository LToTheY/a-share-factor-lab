# 因子研究验收清单

## 数据

- [ ] 使用历史股票池，包含退市股票，避免幸存者偏差。
- [ ] 复权口径固定，并抽样与第二数据源比对。
- [ ] ST、停牌、上市天数均为历史时点状态。
- [ ] 财务字段按公告日对齐。
- [ ] 检查字段单位、重复主键、缺失率和异常价格。

## 信号

- [ ] 所有`shift`和`rolling`都按symbol分组。
- [ ] 所有去极值、标准化和排名都按trade_date分组。
- [ ] 信号时点早于成交时点。
- [ ] 同时展示原始因子与中性化因子的结果。
- [ ] 解释因子方向和经济含义。

## 评价

- [ ] IC、RankIC、ICIR、胜率。
- [ ] 五/十分组收益及单调性。
- [ ] 1/5/10/20日衰减。
- [ ] 因子覆盖率和换手率。
- [ ] 分年度、牛熊市、市值和行业子样本。

## 回测

- [ ] 下一交易日成交。
- [ ] 佣金、印花税、最低佣金和滑点可配置。
- [ ] 100股整数手。
- [ ] 停牌和涨跌停约束。
- [ ] 失败订单不会凭空消失。
- [ ] 报告交易成本占毛收益比例。

## 机器学习

- [ ] 时间切分，不随机打乱。
- [ ] 缺失值、标准化参数只在训练集拟合。
- [ ] 标签区间和训练/验证边界之间留隔离期。
- [ ] 测试集只使用一次，不用于调参。
- [ ] 同时比较等权、Ridge、LightGBM和可选MLP。
- [ ] 用RankIC和组合收益评价，而不只看MSE。
