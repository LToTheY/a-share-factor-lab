# 因子研究验收清单

当前主线为日频价量研究。财报、市值、行业与机器学习条目只有启用对应模块后才适用，
不能为了勾选清单而把未经核验的字段混入研究。

## 数据

- [ ] 使用历史股票池，包含退市股票，避免幸存者偏差。
- [ ] 复权口径固定，并抽样与第二数据源比对。
- [ ] ST、停牌、上市天数均为历史时点状态。
- [ ] 财务字段按公告日对齐。
- [ ] 检查字段单位、重复主键、缺失率和异常价格。

## 信号

- [ ] 所有`shift`和`rolling`都按symbol分组。
- [ ] 所有去极值、标准化和排名都按trade_date分组。
- [ ] 信号时点早于成交时点。
- [ ] 截断未来数据后，过去因子值不变；断档或复权链中断时重新预热。
- [ ] 同时展示原始因子与中性化因子的结果。
- [ ] 解释因子方向和经济含义。

## 评价

- [ ] IC、RankIC、ICIR、胜率。
- [ ] 五/十分组收益及单调性。
- [ ] 1/5/10/20日衰减。
- [ ] 因子覆盖率和换手率。
- [ ] 收盘标签与次日开盘标签分开报告，HAC区间不冒充多重检验校正。
- [ ] 分年度、牛熊市、市值和行业子样本。

## 回测

- [ ] 下一交易日成交。
- [ ] 佣金、印花税、最低佣金和滑点可配置。
- [ ] 按板块最低申报量与步长处理，科创板不能照搬普通100股规则。
- [ ] 停牌和涨跌停约束。
- [ ] 失败订单不会凭空消失。
- [ ] 报告费用金额、费用/初始资金和现金闲置；毛收益接近零或为负时不使用误导性的费用/毛收益比例。
- [ ] 退出缓冲使用实际持仓，未成交目标不算已买入。
- [ ] 小资金空仓、预算不足和失败卖出都可追溯；不为了成交强行增大单股权重。
- [ ] 说明分红送转账本覆盖程度、估值异常和无成本诊断基准的差异。

## 每日人工复核

- [ ] 使用自己选择的实验配置，以及单独保存的现金和完整持仓快照。
- [ ] 行情通过最新日期与窗口检查；代码、配置或账户变更后重算。
- [ ] 买单金额包括费用；使用卖出所得的买单明确标为有条件估算。
- [ ] 留下观察与实际交易记录；系统没有券商连接，也不自动止损。

## 机器学习

- [ ] 时间切分，不随机打乱。
- [ ] 缺失值、标准化参数只在训练集拟合。
- [ ] 标签区间和训练/验证边界之间留隔离期。
- [ ] 测试集只使用一次，不用于调参。
- [ ] 同时比较等权、Ridge、LightGBM和可选MLP。
- [ ] 用RankIC和组合收益评价，而不只看MSE。
