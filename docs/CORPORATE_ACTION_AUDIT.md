# 分红送转核对：价格调整与账户入账是两件事

本项目仍将复权价格用于因子研究，使用原始价格模拟现金和股份账本。
后者尚未完整登记分红送转，长期回测会记录持仓期间疑似除权息的日期；这属于实际限制。

## 本地审计入口

```powershell
.\.venv\Scripts\python.exe scripts\audit_corporate_actions.py
```

脚本读取已经下载的 `trd_cptl` 与正式行情，只生成本机审计产物，不重新下载数据、不改变
正式行情，也不向模拟账户补现金或股份。没有对应原始表时会明确报错。

输出在忽略的 `reports/generated/corporate_action_audit/`：

- `normalized_events.parquet`：标准化字段、事件类型与逐条问题。
- `reference_price_checks.csv`：按股票和除权息日汇总，与相邻交易日昨收核对。
- `summary.json`：覆盖起止、类型数量、匹配与待核对计数。

审计要求有公告日、除权息日、派发日和有限非负金额；重复事件、日期关系异常与暂不支持
的配股等事件保留并标记。没有同一股票相邻市场交易日的价格时，不跨缺口推算前收。

## 字段依据与单位

CSMAR 说明书的 PDF 第22、41页说明：CA 是每股现金分配，SD 是每股新增股份比例
（包括送股与资本公积转增），派发日用于表示现金到账或新增股份可以交易的日期。
因此现金0.6元与送转0.2同时发生时，简单核对公式是 `(前收盘价 - 0.6) / 1.2`。
不能把“每股”误当作“每10股”，也不能把新增股份比例直接当作总股份倍数。
[CSMAR说明书](https://cn.ceibs.edu/pdf/library/40030.pdf)

这一公式仅用于简单情形的检查。差异化分红可能使用按总股本摊薄的虚拟分配额计算参考价，
它与普通投资者实际每股到账金额不同。公司公告中可以看到这一区分。
[冠盛股份2024年度权益分派实施公告，第2页](https://static.cninfo.com.cn/finalpage/2025-06-12/1223848451.PDF)

因此，“参考价不匹配”不直接等于数据错误；它可能来自差异化分配、数据口径或特殊事件。
必须逐案核对公告。现有脚本不会通过调节现金红利来强行匹配行情。

## 下一步接入账本的验收条件

1. 明确事件表的完整覆盖期，覆盖期外不能把“没有记录”解释为“没有分红”。
2. 权益登记时冻结有权获得分配的股份数量；除权日确认应收，到账日再进入可买股票的现金。
3. 区分新增股份的权益与可交易时间，处理零碎股及卖出限制。
4. 单独验证配股、股息红利税、特殊重整和差异化分红，不能只按昨收差额反推账户收益。
5. 用合成账本逐项核对现金守恒与股份变化，再用可核查的公告案例验证。

目前的参考价匹配和因子复权都不能替代上述账户验收。
