# 因子、策略与小资金实验怎么分工

维护：2026-09-30。配套入口：[项目使用教程](USER_GUIDE.md)、[新手课程](BEGINNER_COURSE.md)、[成交假设](EXECUTION_ASSUMPTIONS.md)。

## 先区分三个问题

1. **因子有没有信息？** 在历史时点股票池内比较覆盖率、RankIC、分层和年度稳定性。
2. **组合能否兑现信息？** 明确因子方向、权重、调仓规则、实际持仓、成本与样本外验证。
3. **自己的账户能否执行？** 按可用现金、股票价格、最低申报量、交易权限及实际持仓生成复核清单。

这三个问题不能用同一条漂亮的收益曲线替代。几千元买不起一只高价股，并不意味着它不能参加因子研究；但它可能不能进入该账户的目标组合。

## 当前可研究的日线模块

| 模块 | 示例 | 待验证的假设 |
|---|---|---|
| 趋势延续 | momentum_20_5、momentum_60_5、momentum_120_20 | 跳过最近短期波动后，较强趋势会延续 |
| 价格反转 | reversal_5、reversal_20 | 最近弱势可能反弹；成本可能吞掉信息 |
| 波动与下行风险 | volatility_20、volatility_60、downside_volatility_20 | 波动或下行波动较低的股票可能表现不同 |
| 流动性与交易活跃度 | amihud_20、turnover_mean_20、amount_momentum_20 | 交易拥挤、流动性或活跃度变化可能有预测信息 |
| 量价关系 | price_volume_corr_20 | 价格和成交额变化的关系可能有信息 |
| 隔夜与盘内拆分 | overnight_reversal_5、intraday_momentum_20 | 隔夜缺口和日内开收盘收益可能对应不同机制 |

后三个新候选因子的定义：

- `downside_volatility_20`：近20日 `min(日收益, 0)` 平方的均值开方，至少15个有效值。上涨日贡献0，并非只保留下跌日计算标准差。低下行风险假设使用负方向。
- `overnight_reversal_5`：近5日 `调整后开盘价 / 上一日调整后收盘价 - 1` 的均值取负，需要5个有效值。正方向代表隔夜反转假设。
- `intraday_momentum_20`：近20日 `收盘价 / 开盘价 - 1` 的均值，至少15个有效值。它使用日线开收盘价，不是分钟策略。

这些只是研究候选，不会自动加入默认11因子组合。研究界面允许选择它们；新增候选不等于已证明有效。所有滚动计算在股票与连续研究区间内进行，跨未知行情缺口重新预热。

## 两种收益标签

- 收盘标签：`close(t+h) / close(t) - 1`，方便与既有研究比较，但收盘后才得到的信号未必能捕获其中第一段隔夜收益。
- 次日开盘标签：`adj_open(t+h+1) / adj_open(t+1) - 1`，表示信号形成后次日开盘进入，持有h个交易日后开盘退出。

两者均为无成本、未加入成交约束的诊断标签。真实模拟成交仍需经过账本。次日开盘标签跨度多1期，训练/验证末尾至少隔离 `h+1` 个交易日，防止标签使用下个窗口的价格。

分层均值不是可以直接复利的净值；重叠5日收益不能每天当成独立5日交易重复相乘。

## 分层与未来标签覆盖

分层组成员在信号日按原始因子分数确定。未来标签缺失时，保留分组并报告
`assigned_count`（当时分入的数量）、`observed_count`（实际可评价数量）与 `label_coverage`。
不能先删除未来没有价格的股票，再重新切分组界；那会让未来数据影响当时分组。
缺失标签也不按0收益填补，分层均值仍可能有样本选择偏差，需连同覆盖率解释。
编号越大只表示原始分数越大；配置负方向时，研究假设偏好较低编号组。

## IC的不确定性

每日5日收益标签互相重叠，所以每日IC通常并不独立。界面提供Bartlett权重的Newey–West/HAC均值标准误、t值和正态近似95%区间，滞后阶数至少覆盖标签重叠。实现口径参考 [statsmodels的HAC说明](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)。

这个区间未校正尝试多个因子、方向、窗口和股票池带来的多重检验。区间没有跨0，也不能直接解释为“策略可盈利”。要同时看年度稳定性、有效日数、可交易标签、成本和样本外结果；保留失败研究。

## 小资金选股的两种模式

因子合成还可从“模块等权、模块内等权”起步，避免仅因为某个模块写了更多相似因子，
它就在等权组合里获得更多票数。示例：3个动量因子每个相对权重1/3，2个反转因子每个1/2。
这只是研究起点；仍应核对因子相关性、缺失值、方向和不同年份表现，不会自动删除或挑选因子。

**按排名选股**：选排名和退出缓冲决定的目标；买不起时可能长期空仓，适合作为资金约束对照。

**按预算筛选可负担候选**：每个名额的预算固定为 `账户权益 × min(1/TopN, 单股上限) × (1-现金预留)`。按信号日收盘价、估计滑点及最低佣金计算最低申报成本，跳过无法负担的新候选。少选几只时不提高剩余股票的权重来凑满仓。

两种模式均使用**实际持仓**决定退出缓冲。未成交目标不会被当成已持仓股票。科创板和创业板可独立关闭；勾选只表示研究假设，不证明券商账户已有权限。

预算筛选可能偏向低价股，改变策略暴露；提升资金利用率并不保证提高收益。对照时固定因子、区间、股票池和费用，仅改变选股模式，再比较实际持仓、现金闲置、交易次数和净收益。

## 样本外验证与空仓

策略实验室：使用你固定的因子权重和交易参数，各测试折独立从初始资金开始；训练/验证窗口只诊断，不按测试期收益选参数。

默认研究报告：沿用训练、验证均为正IC的筛选规则。某折无因子通过时产生空仓指令，在计划调仓时执行；不把上一折组合偷偷延续。最后不足一年的测试明确标记为不完整年度。

查看过的历史测试只能作为探索证据。改完规则后重新跑同一测试段，不会凭空得到新的样本外证据。应冻结研究假设和参数，继续积累未来的观察或模拟记录。

## 每次研究交付什么

保存一句可证伪假设、完整配置与来源、正反两方面结果、费用与现金利用率、样本外及单因素对照、失败原因与下一步。不要仅导出收益最高的一次。

45分钟练习：5分钟解释标签时点；30分钟在同一策略上比较两种选股模式；10分钟写出“利用率是否提高、收益是否提高、为何不能混为一谈”。验收时能从逐日回放指出至少一笔未成交，并解释其具体原因。
