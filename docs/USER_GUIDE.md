# 项目使用教程

本项目提供日频价量研究：数据检查 → 因子研究 → 策略实验 → 实验历史 → 教程。
网页和命令行使用同一个研究服务。无需开发另一个后端，也不会自动下单。
学习路线见 [小白课程](BEGINNER_COURSE.md)，数据口径见 [数据使用说明](DATA_USAGE.md)。
因子模块与评价方法见 [因子研究方法](FACTOR_RESEARCH_METHOD.md)，自己的策略与账户信号见 [每日人工复核](MANUAL_REVIEW.md)。

## 1. 安装与启动

本机环境已经安装好时，可直接双击项目根目录的 `start_dashboard.cmd`。
它只启动本机网页，不运行调仓或下载任务。终端窗口需保持开启，关闭即停止网页服务。

在项目根目录打开 PowerShell。已有 `.venv` 时直接运行最后一行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[free-data,dashboard,dev]"
.\scripts\run_dashboard.ps1
```

打开终端显示的本机网址。不要把研究看板部署到公共网络；自定义 Python 因子是可信本地代码。

若Windows提示PowerShell脚本被禁用，不必改全局执行策略。改用上述CMD入口，或直接运行
`.\.venv\Scripts\python.exe -X utf8 -m streamlit run dashboard/app.py --server.address 127.0.0.1`。
项目中的PowerShell脚本使用UTF-8 BOM，兼容Windows自带PowerShell 5.1解析中文。
WRDS 是可选的下载依赖；没有账号也能学习全部研究流程。

安装或迁移后可运行 `.\.venv\Scripts\python.exe scripts\doctor.py --profile dashboard`。
它检查当前项目的导入路径、网页依赖及版本，并用随机文件名测试写权限，结束后删除自己的探针。
`missing_required` 和 `compatibility_errors` 应为空；缺少未启用的机器学习或WRDS依赖不阻止网页使用。
启动脚本默认只监听本机；其他端口例如 `.\scripts\run_dashboard.ps1 -Port 8502`。

网页使用的自适应图表接口要求 Streamlit 1.51 或以上、低于2；Pandas维持2.2至2.x，
兼容当前WRDS下载环境。已测试的本机实际版本可从doctor输出核对。API下限依据
[Streamlit 1.51图表说明](https://docs.streamlit.io/1.51.0/develop/api-reference/charts/st.plotly_chart)。

## 2. 没有国泰安账号：先走合成演示

网页进入“运行因子研究”，打开“合成数据演示”，选择 `range_position_20`，
研究区间使用 2016-01-01 至 2024-12-18，股票池选择并集，点击“启动因子研究”。
演示数据由固定随机种子生成，包含30只虚构股票、约10年工作日；不模拟真实交易所日历。
所有演示收益只用于检验流程，不能作为真实策略业绩写入简历。

任务区每5秒自动刷新，也可点击“刷新任务状态”；成功后“打开研究结果”。也可以使用命令行：

```powershell
.\.venv\Scripts\python.exe scripts/run_factor_suite.py --demo
```

命令行默认演示 `reversal_5`，报告在 `reports/generated/demo/`。
网页可在“已保存的研究报告”中切换它。模拟账户与演示资金相互独立。

## 3. 已有真实数据：先检查日期

“系统总览”展示当前打开的历史研究报告，不表示行情已经更新到今天。
进入“今日调仓检查”点击“更新数据并检查调仓”：系统联网补必要近期数据，
检查完整性后生成本次排名和纸面操作清单。北京时间18:00前以此前最近交易日为目标。
任务失败、状态未知或数据未齐时不会展示旧建议冒充最新结果。
本页使用项目默认策略和演示模拟账户。自己的资金与持仓应在“我的策略每日复核”中建立独立方案。

日常命令行入口：

```powershell
.\.venv\Scripts\python.exe scripts/daily_update.py
```

近期检查与历史库更新是两个层次。需要把新增日期写入全历史库并重建完整报告时：

```powershell
.\.venv\Scripts\python.exe scripts/daily_update.py --full-research
```

它复用既有分区，只补必要增量；不用重新下载国泰安全量数据。
数据来源、路径、权限及恢复方法详见 [DATA_USAGE](DATA_USAGE.md)。

## 4. 编写与研究因子

打开 `src/quant_lab/factors/custom/range_position_20.py`，这是可直接运行的价量练习。
复制为新文件时换一个小写文件名，并填写 `TITLE`、`DESCRIPTION`、`DIRECTION`、
`LOOKBACK`、`REQUIRED_COLUMNS` 和 `compute(frame)`。
返回与输入索引一致的数值 Series；不能使用 `shift(-1)`、未来收益或全样本标准化。

在网页“更新代码因子”后检查校验结果，再在研究表单中选择因子并提交。
系统根据声明加载高、低、收、成交额等实际字段，自动加入预热历史。
历史不足或字段缺失会说明原因。股票池选择历史沪深300、中证500或并集，
每次都按照该池重新做截面处理，而不是筛选另一股票池的旧分数。
完整说明：[自定义因子](CUSTOM_FACTORS.md)。

## 5. 任务与结果版本

同一时间只允许一个网页重型任务。重复点击同一请求不会重复启动。
任务状态和日志保存在 `data/state/jobs/`，关闭网页后任务仍可运行，但电脑需要保持开机。
取消为协作式取消：当前计算单元结束后停止。失败和取消不覆盖成功报告。
断电遗留任务会标记进程退出，可以重新提交。

成功研究在 `reports/generated/jobs/<任务编号>/`；每次独立保存。
`result_manifest.json` 记录配置与来源，`dataset_provenance.json` 绑定数据哈希、
股票池、代码指纹和自定义代码。数据或代码变化会提示历史版本；旧结果仍可阅读，
新策略需要重新研究，不能混合新行情与旧分数。

新记录还包含数值库与Python版本。因子输入或计算逻辑变化时必须重算分数；
只有回测或其他程序部分变化时，可复用一致版本的分数重新做策略实验，原报告仍标为历史版本。

## 6. 因子诊断与策略实验

先查看覆盖率、RankIC、分层、年度稳定性、相关性，写下一个可被否定的假设。
分层编号按原始因子处理分数排列，负方向通常偏好较低组。组成员在信号日确定，
未来标签缺失只降低评价覆盖率，不根据未来是否有价格重新分组。
然后配置策略的因子权重和方向、研究区间、持股数、退出排名、单股上限、调仓频率、费用。
策略方向是相对于研究报告已经设置的方向；不要看到全样本负IC后直接翻转方向并声称发现规律。

“模块等权（模块内等权）”模板先按参考模块分配相同总权重，再在模块内等分。
例如3个动量因子各1/3、2个反转因子各1/2，再由组合统一归一化；它不等于风险等权，
也不证明模块相互独立。参考模块可在表格中查看，自定义因子统一显示“自定义/其他”。
载入旧实验后，其权重和方向直接填入可编辑表格；修改表格会进入新请求。
要重新应用模板，先清除已载入参数，避免模板暗中覆盖历史实验配置。

小资金默认5,000元，也可选3,000或10,000元。从1只起设置目标持仓。
例如5,000元、5只、每只上限20%，单票预算约1,000元，一股30元的股票通常无法买入一手。
目标持仓并不等于实际持仓，应查看现金闲置、未成交原因和费用占比。
模型边界见 [成交假设](EXECUTION_ASSUMPTIONS.md)。

勾选 Walk-forward 会用**当前实验配置**，默认5年训练、1年验证、1年测试。
训练和验证窗口保留隔离期，长度至少覆盖预测期；参数和因子权重预先固定，不按测试收益选优。
窗口不足会保留正常回测并明确提示无法完成验证。
每折独立从初始资金开始，不能直接把各折收益拼成连续实盘净值。

有限对照分别改变 Top N、周/月频、费用与滑点。其余参数保持不变：
Top N 大于基线退出排名时该组显示无效，避免偷偷改两个参数。
比较表不按测试期挑选最佳策略，所有成功及失败结果均保存。

## 7. 保存、重开、比较和导出

成功实验自动保存到 `data/state/strategy_experiments/<编号>/`。
“实验历史”可查看原配置、研究假设、净值、回撤、实际持仓、逐日成交、
本实验样本外折与所有对照。结论单独存入 `notes.json`，原始结果不可变。
选择第二个实验比较参数与结果；区间或数据指纹不同会提示不能直接归因。

“载入此实验参数到策略实验室”恢复配置，再次运行生成新记录。
支持下载配置 JSON 和完整 Markdown 报告。对照组逐日账本在对应任务目录的
`robustness/` 下，样本外账本在 `validation/fold_*/` 下。

“批量研究档案”提供事先声明的股票池/因子/选股方式对照，保留失败和未完成项，
可查看现金闲置与收益关系、打开对应池的因子报告并导出完整复盘。历史代码结果有独立提示。

旧单因子命令 `scripts/run_research.py --factor momentum_60_5 --top-n 5` 也改用统一研究服务，
保留原参数并支持 `--start`、`--end`、`--direction`。默认行情改为正式库，报告采用
`factor_scores.parquet` 等统一格式；不再重复输出很大的逐行 `factor_research.csv`。

## 8. 常见问题

| 提示 | 处理 |
| --- | --- |
| 缺少行情 | 无账号先运行合成演示；已有授权数据按数据说明导入 |
| 预热不足 | 推迟研究起点，或在确认权限后补充更早历史 |
| 股票池或字段缺失 | 检查数据版本和因子 REQUIRED_COLUMNS，不要随便填零 |
| 数据或代码版本变化 | 重跑因子研究，成功后打开新报告 |
| BaoStock连接失败 | 保留已有数据，稍后重试；旧排名不能代替最新判断 |
| 已有重型任务 | 查看任务状态，等待或取消；日志显示当前计算阶段 |
| 没有成交 | 查看最低申报量、费用、现金、停牌和未知状态记录 |
| 磁盘预留不足 | 查看总览容量及DATA_USAGE中的预算配置；程序停止下载并显示失败，不自动删除原始数据 |
| Walk-forward窗口不足 | 扩大有数据的区间；不要把样本内回测称为样本外 |

运行检查：

```powershell
.\.venv\Scripts\python.exe scripts/run_tests.py
.\.venv\Scripts\python.exe -m ruff check .
git diff --check
```

测试入口统一为 pytest；`scripts/run_tests.py` 为兼容包装，会运行 pytest 函数测试及 unittest 类测试。
