# 数据契约

核心表采用长表，一行代表一只股票在一个交易日的数据，主键是
`(trade_date, symbol)`。

## 必需字段

| 字段 | 单位 | 含义 |
|---|---:|---|
| trade_date | 日期 | 交易日，归一化到00:00 |
| symbol | 字符串 | 带交易所的证券代码 |
| open/high/low/close | 元 | 当日不复权OHLC，只用于成交、整手和现金账本 |
| adj_open/adj_high/adj_low/adj_close | 连续价格 | 后复权研究价格，用于因子与收益标签 |
| volume | 股 | 成交股数，不是“手” |
| amount | 元 | 成交额，不是千元 |
| adj_factor | 倍数 | `adj_close / close`，用于检查两套价格的对应关系 |

## 建议字段

| 字段 | 含义 | 时点要求 |
|---|---|---|
| market_cap | 当日总市值（元） | 当日收盘后可见 |
| float_market_cap | 当日流通市值（元） | 当日收盘后可见 |
| industry | 行业分类 | 必须尽可能使用历史分类 |
| list_date | 上市日 | 静态基础信息 |
| is_st | 当日是否ST | 必须是历史状态，不能用当前名称反推 |
| is_suspended | 当日是否停牌 | 当日状态 |
| is_limit_up/down | 当日是否封涨/跌停 | 执行约束，不应提前删除持仓 |

## 不变量

- 主键不能重复。
- 原始和复权OHLC必须为正，high不能低于其他价格，low不能高于其他价格。
- 不能用前/后复权价格计算真实下单股数、最低佣金或现金余额。
- volume和amount不能为负。
- 下载器保存供应商原始分区；清洗过程不得覆盖原始文件。
- Tushare的`vol`是“手”、`amount`是“千元”，进入核心表时转换为股和元。
- 财务数据必须按公告日/可见日对齐，不能按报告期直接向前填充。
