# 成交模型与限制

核验日期：2026-09-30。日频研究先在收盘形成目标，下一实际交易日用原始开盘价加滑点模拟。
先卖后买，不卖出当天新买的股票；资金必须覆盖买价和费用。佣金最低额和卖出税单独计入。

沪深普通A股买入按100股整数单位；科创板688/689代码按至少200股、超过部分1股递增。
卖出不足最低数量的剩余持仓时允许一次卖完。低于最低申报量的部分调整不会成交。
规则依据：[上交所投教第7问](https://edu.sse.com.cn/tib/qa/c/4761956.shtml)，
现行规则版本见 [上交所2026年交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。
项目限于沪深股票池，不覆盖北交所、融资融券或盘后交易。

模型拒绝在已知停牌、涨停买入、跌停卖出、未知状态或异常行情时成交。
现有涨跌停标记是日频近似，不能还原开盘队列或盘中能否成交；不包含冲击成本和排队撮合。
板块准入权限需要投资者本人核对，研究股票池并不表示个人账户有交易权限。

因子和标签用调整后价格，成交股数和费用用原始价格。现金分红、送转股、退市清算
尚未逐项进入账本，策略与调整价诊断基准的差异可能包含公司行动影响。
这会限制长期收益比较的精度，不能把研究回测当作券商账户收益。
持仓当日缺少有效收盘价时保留持股，暂沿用上次估值并逐日记录 `VALUATION` 异常，
不把持仓价值直接抹为零；这种估值不代表退市清算价，也不是已实现回收金额。

平均实际持股数按全部回测交易日的收盘持仓计算，空仓日计0。
费用比例为账本佣金、过户费与税相对初始资金，滑点已反映在成交价中，未重复算入该费用合计。
研究假设、样本外折及所有失败对照应同时保存，不能只展示最好参数。
