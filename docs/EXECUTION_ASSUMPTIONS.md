先卖后买，不卖出当天新买的股票；资金必须覆盖买价和费用。佣金最低额和卖出税单独计入。

配置中的历史倍率为2，费用敏感性实验调高当前基准时，历史费率按同一倍率缩放。

极小金额卖出的可用现金和收入不足费用时拒绝成交；已知涨跌停价会约束模拟滑点价格。
触及价格边界不表示一定能成交，日线无法验证排队情况。

项目限于沪深股票池，不覆盖北交所、融资融券或盘后交易。

模型拒绝在已知停牌、涨停买入、跌停卖出、未知状态或异常行情时成交。
现有涨跌停标记是日频近似，不能还原开盘队列或盘中能否成交；不包含冲击成本和排队撮合。
板块准入权限需要投资者本人核对，研究股票池并不表示个人账户有交易权限。

因子和标签用调整后价格，成交股数和费用用原始价格。现金分红、送转股、退市清算
尚未逐项进入账本，策略与调整价诊断基准的差异可能包含公司行动影响。
这会限制长期收益比较的精度，不能把研究回测当作券商账户收益。
持仓当日缺少有效收盘价时保留持股，暂沿用上次估值并逐日记录 `VALUATION` 异常，
不把持仓价值直接抹为零；这种估值不代表退市清算价，也不是已实现回收金额。

平均实际持股数按全部回测交易日的收盘持仓计算，空仓日计0。
费用比例为账本佣金、过户费与税相对初始资金，滑点已反映在成交价中，未重复算入该费用合计。
研究假设、样本外折及所有失败对照应同时保存，不能只展示最好参数。

## 本轮账本修正

- 收盘后按实际已成交持仓决定退出缓冲，未成交目标不被当作持仓。
- 小资金可以先按信号日预算筛选候选；不会使用次日价格提前判断买得起哪只。
- 开盘成交不读取当天尚未发生的收盘价格。新买持仓若缺失当日收盘价，暂用该日原始开盘价估值并记录异常；已有持仓沿用上次有效估值。
- 资金不足时按信号排名顺序分配买入预算，费用和滑点参与资金上限计算。
- 对照基准的每段收盘到收盘收益使用上一交易日收盘的成员标记，避免用当日新名单获取已经发生的收益；仍是无成本的等权诊断，不是官方指数。
- 输入含交易所昨收价时，持仓跨日检测到前收与交易所昨收变化，记录 `CORPORATE_ACTION`。这是公司行动或参考价变化提示，不推断具体送股数量，也不冒充已经完整记账。

选股模式、现金预留和板块范围在实验参数中保存。空仓也是合法研究结果；查看选股筛选记录，区分没有可负担候选、未到调仓日和执行受阻。
