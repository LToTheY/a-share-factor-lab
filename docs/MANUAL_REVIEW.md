# 用自己的策略和账户做每日人工复核

此流程只读取行情、计算信号并估算交易清单，没有券商接口，也不会自动下单。账户数据只在本机保存。

## 第一次使用

1. 先在“运行因子研究”使用真实数据完成研究，再在“策略实验室”保存实验。检查样本外表现、成本、回撤、实际持仓和现金闲置。合成演示不能用于建立实际复核方案。
2. 在“我的策略每日复核”选择已保存实验。填写当前可用现金，在表格逐行填写股票代码和股数，空仓保留空表。注意数量单位是“股”，不是“手”。也可切换 JSON 输入，例如 `{"000001.SZ": 100}`，空仓为 `{}`。只填代码和股数，不填账号、密码或验证码；使用练习账户时在“账户快照说明”明确标注假设资金。
3. 自行设定可承受亏损与停止条件。页面中的金额是记录，不会触发自动止损。
4. 点击“保存本机方案并更新数据”。后台重新核对日历、成分和观察窗口，并按该实验的因子、权重、方向、股票池和调仓频率计算。
5. 更新成功后查看行情截止日、计划交易日、候选筛选原因和估算清单。周频或月频策略在非调仓边界显示无需调仓。

## 每次使用

电脑和应用需要保持运行。任务状态可在刷新页面后查看；失败或取消不会成为成功信号。盘中仍使用上一个完成交易日；项目约定北京时间18:00以后要求当天日线，但不保证数据商届时已经发布。

没有交易、账户数据未变化时，可以重新更新同一方案。发生买卖、转入转出资金或股份变化后，填写最新快照建立新方案。程序不推断你已经成交，也不改原有100万元演示模拟账户。

候选生成使用收盘数据。估算股数考虑最低申报量、滑点、费用和现金，仍无法知道下一交易日开盘价格、停牌、涨跌停或实际成交顺序。标记“依赖卖出”的买单，只有卖单实际成交并确认资金后才能重新考虑。

## 明确阻止发布的情况

- 网络、日历、成分或历史窗口检查失败；
- 数据过期，配置、代码或账户快照变化；
- 目标股票或持仓没有有效估值；
- 来源是合成数据、未知来源或因子代码已变化；
- 找不到与实验一致的原始研究配置与分数快照。

尚未完成足够样本外验证的实验会显示提示，可用于观察和模拟记录，不能因此声称策略已经验证。

## 本机记录位置

路径均相对项目根目录：

- `data/state/manual_review/<方案编号>/profile.json`：来源实验、版本与验证状态；
- 同目录 `research.yaml`：被冻结的策略与研究配置；
- 同目录 `account_snapshot.json`：你填写的账户快照；
- 同目录 `status.json`：最新更新状态及文件指纹；
- `reports/generated/manual_review/<方案编号>/runs/<运行编号>/`：每次成功的信号、目标、筛选原因和估算清单；
- `data/state/jobs/`：后台任务状态与日志。

上述目录全部被Git忽略。公开项目只提供代码和示例，不包含真实账户或行情明细。
