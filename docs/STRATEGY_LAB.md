# 策略实验室使用说明

策略实验室是网页中的隔离研究沙盒。它使用已经生成的因子分数和现有A股回测引擎，允许组合因子、调整持仓规则和交易成本，但不会修改正式研究报告、模拟账户或下一交易日订单。

## 基本流程

1. 选择一个起始模板。
2. 启用因子并设置相对权重。
3. 设置日期、Top N、退出排名和调仓频率。
4. 核对佣金、印花税、滑点和最低佣金。
5. 点击“运行策略回测”。
6. 同时检查收益、基准、回撤、换手、费用和年度稳定性。
7. 成功运行的实验会自动保存到本机，在“实验历史”查看条件、比较实验和回放交易日。
   后台状态和错误会落盘，失败时保留此前成功实验，可重新提交。

## 回测工作区

- **条件摘要**显示实际回测区间、调仓频率、资金、费用、成交时点和数据来源。
  下方的结果条件来自已完成实验，不跟随尚未运行的表单修改。
- **实验历史**保存每次成功运行的独立快照，包括策略、成本、请求及实际区间、
  输入数据指纹、净值、目标、成交、持仓和执行受阻记录。可并排查看参数差异及绩效。
  输入数据或样本区间不一致时会提示不可直接归因；不同区间不叠加净值。
- **逐日回放**将信号日目标映射到下一个实际交易日，分开展示目标、成交、收盘持仓和现金。
  新回测会记录停牌、涨跌停、现金不足（含部分成交）、不足一手、缺少行情等原因。
  不记录原本就无需交易的持仓；不足一手的数量为0，表示未形成整手委托。
- 本地路径为 `data/state/strategy_experiments/<实验编号>/`，默认不提交 Git。
  保存中断的 `.pending-*` 目录不会作为成功实验展示。数据仅保存于本机。
- 保存的是配置、结果和输入指纹，不是完整行情与代码环境备份；重新计算仍需相同输入及代码。
- 正式“回测分析”也支持逐日回放。旧报告没有参数快照或未成交记录时明确显示缺失；
  下次运行正式研究流程会生成这些记录，不会用当前配置回填历史。

## 参数解释

- **相对权重**：只决定因子之间的比例，`2:1`与`1:0.5`等价。
- **方向**：默认沿用项目中经过配置的方向；反向用于检验相反假设。
- **Top N**：每次调仓希望持有的股票数量。
- **退出排名**：已有股票跌到该排名以外才退出，用于降低不必要换手。
- **单股上限**：限制单只股票的目标权重。如果 `Top N × 单股上限 < 100%`，剩余资金保留为现金。
- **最低因子完整度**：一只股票至少需要多少比例的所选因子有效，才计算综合分。

## 当前边界

- 只支持多因子综合排名后的长期 Top-N 策略。
- 使用所选区间做实验，结果属于样本内表现。
- 正式结论仍需 Walk-forward 样本外验证、参数敏感性和成本压力测试。
- 不允许网页直接写入模拟账户或发送真实订单。
- 当前读取 CSMAR 优先、BaoStock 补缺的正式库，支持历史沪深300、中证500与并集。
- 支持3,000/5,000/10,000元预设、1只起持仓；显示实际持股数、现金闲置与费用占比。
- 每次实验可运行自身的固定参数Walk-forward和单因素对照，窗口不足明确提示。
- 完整操作与可复现练习见 [使用教程](USER_GUIDE.md) 和 [小白课程](BEGINNER_COURSE.md)。
