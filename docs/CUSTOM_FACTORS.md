# 自己编写 Python 因子

## 网页直接运行

在“运行因子研究”选择内置/自定义因子、历史股票池和区间，点击“启动因子研究”。
成功后打开结果，再进入诊断与策略实验；下文下载配置是可选的命令行方式。
参考因子 `range_position_20.py` 可直接运行，完整练习见 [小白课程](BEGINNER_COURSE.md)。
每次研究加载声明的字段并检查预热，结果绑定代码与行情版本。

## 1. 文件放在哪里

在项目的 `src/quant_lab/factors/custom/` 目录新建一个 **UTF-8 编码的 `.py` 文件**。
推荐复制 `_template.py` 为 `my_momentum.py`，然后修改公式。
文件名（不带 `.py`）就是因子标识。只能使用小写字母、数字、下划线，并以字母开头。
以下划线开头的文件是模板/辅助文件，不加载；不要与内置因子重名。
每个因子文件应自包含，首版不支持同目录相对导入。

## 2. 模板中的字段

| 字段 | 填什么 |
|---|---|
| `TITLE` | 页面显示名称 |
| `DESCRIPTION` | 公式含义和研究假设 |
| `DIRECTION` | 事先约定 1（越大越好）或 -1（越小越好） |
| `LOOKBACK` | 当前行之外需要多少行历史，整数 0～2000；复合窗口要累计计算 |
| `REQUIRED_COLUMNS` | 所需数据字段，如 `["adj_close", "amount"]` |
| `compute(frame)` | 返回与输入同长度、同索引、同顺序的数值 `pd.Series` |

`frame` 已按 `symbol, trade_date` 排序。每一行代表一只股票一天的观测。
`symbol` 和 `trade_date` 总是可用，其他用到的列都应声明。
常用列：复权价格 `adj_open/adj_high/adj_low/adj_close`、`volume`、`amount`、
`turnover_rate`。具体可用字段仍以所选真实数据为准。
校验样本另提供 `market_cap` 等模拟字段，不代表真实库已经有时点财务数据。

## 3. 计算规则

- 时间序列 `shift/rolling` 必须按 `symbol` 分组；截面排名按 `trade_date` 分组。
- 收益和趋势用复权价格；窗口不足返回 `NaN`，不要用 0 冒充缺失。
- 保留原索引。`groupby().rolling()` 得到多级索引时需还原并 `reindex(frame.index)`。
- 不使用 `shift(-1)`、未来收益、居中滚动窗口或全样本均值等未来信息。
- 某些链路会为断裂的历史段给 symbol 加后缀；将 symbol 当分组键，不硬编码具体股票。
- 因子模块只定义常量和函数，不在文件顶层启动下载、写文件、训练或循环。
  点击更新会执行本机 Python 文件，请只放自己编写或审阅过的代码。

## 4. 在前端更新

保存文件后，进入 **因子库 → 日频 → Python 自定义因子 → 更新代码因子**。
会显示每个文件是否加载成功及失败原因，不需要修改 `FACTOR_REGISTRY`。
修改文件后再次点击更新，即加载最新代码；删除文件后更新会移除该代码因子。
有错误的新版本会退出可执行列表，不会悄悄沿用旧版本。
重启网页或命令行研究进程时，会重新从该目录加载文件。

检查包含返回类型、索引、无穷值、合成样本和截断未来数据的一致性。
**检查通过不证明没有所有形式的数据泄漏，也不证明有预测能力。**
某些事件因子在合成样本上全部为空时会被拒绝，需要先调整测试设计/输入支持。

## 5. 怎样进入评价和策略实验

“更新代码因子”只加载公式，不会自动计算全历史分数、覆盖原研究报告或加入每日策略。
推荐在“运行因子研究”表单选择该因子并直接启动后台任务。
也可下载 **独立研究配置**，保存到 `configs/custom_research.yaml` 后运行页面给出的命令。
研究使用现有本地数据，不自动下载行情。
配置包含所选因子的方向和独立输出目录，最少有效因子数设为所选数量。
完整流程会产生单因子诊断、分数、组合回测和滚动验证，耗时取决于本地数据量。

研究完成后，刷新因子库页面，在“打开研究结果”中选择对应时间编号的报告并点击打开，
即可在因子研究、策略实验室及回测页面使用新分数。也可切回默认研究报告。
修改代码后需要重新运行研究；旧报告不会因点击更新而变成新公式的结果。
首次编写优先用小规模数据验证，正式研究另做样本外检验。

将因子用于每日检查前，另行确认其所需字段及 `current_check.lookback_sessions`
是否足够，不能把加载成功当作每日策略上线。
