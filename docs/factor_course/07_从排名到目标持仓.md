# 第7课：从排名到目标持仓

## 本课只解决一个问题

> 每天都有股票排名，为什么不是每天交易？Top20和Rank30退出缓冲怎样工作？

## 本课目标

- 区分每日信号、调仓信号和订单；
- 理解周频调仓；
- 手工执行一次Top20/Rank30缓冲；
- 理解目标权重与实际持仓不同。

## 一、每天排名不等于每天交易

项目每天计算最新分数，便于观察。但配置 `W-FRI` 只在每个自然周最后一个可用交易日形成目标权重。所以 `latest_signal.csv` 可以有完整排名，而 `next_day_orders.csv` 显示 `NO_TRADE`。

## 二、Top20等权

选择排名1至20，每只5%。若只有15只有效股票，每只仍受5%上限，组合只投资75%，其余留现金。

## 三、为什么加入退出缓冲

没有缓冲时，第20名和第21名的小幅交换会造成反复买卖。当前规则：

- 新股票原则上从排名顶部进入；
- 旧持仓只要仍在前30名就保留；
- 跌出前30名才退出；
- 空位再由高排名未持仓股票补充。

## 四、缩小版手算

把Top20缩成Top3、退出线缩成Rank5。上期持仓是A、B、C，本期排名：

```text
1 D
2 A
3 E
4 B
5 F
6 C
```

旧持仓A、B仍在前5名，先保留；C第6名退出。再从顶部补未持仓的D。新持仓为A、B、D。E虽然第3名，但没有空位。

缓冲牺牲一部分最新排名，换取较低换手。

## 五、代码位置

打开 `src/quant_lab/portfolio/weights.py`，只读：

- `rebalance_dates()`；
- `buffered_top_n_weights()`。

观察 `previous`、`kept` 和 `rank_map` 怎样保存上期状态。

## 六、目标权重不等于实际持仓

目标写5%，实际可能不同，原因包括：

- 100股整手取整；
- 现金不足；
- 涨停买不到；
- 停牌无法交易；
- 卖出受阻，旧持仓仍占资金；
- 滑点和费用。

`target_weights.csv` 是计划，`positions.csv` 才是模拟实际持仓。

## 七、本课实践

1. 从 `target_weights.csv` 找连续两个调仓日；
2. 列出两天股票集合；
3. 找到排名21至30仍被保留的旧持仓；
4. 计算新进、退出和保留数量；
5. 对照 `trades.csv` 看是否全部成功成交。

## 八、闭卷自测

1. 为什么每天有排名却不一定有订单？
2. 旧持仓跌到第25名会怎样？
3. 新股票第21名会自动进入吗？
4. 缓冲的好处与代价是什么？
5. 目标权重为什么不等于实际权重？

## 参考答案

1. 每天算信号，但只在预定周频边界调仓。
2. 仍在Rank30缓冲内，继续持有。
3. 不会，通常只有旧持仓退出形成空位时才从高排名补入。
4. 降低换手和成本，但可能保留已经变弱的股票。
5. 整手、现金、费用和交易约束会造成偏差。

## 最低过关标准

完成两期手工持仓表，能正确处理“旧持仓第25名”和“旧持仓第31名”。
