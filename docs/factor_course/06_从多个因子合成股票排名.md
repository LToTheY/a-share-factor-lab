# 第6课：从多个因子合成股票排名

## 本课问题

> 11个单因子怎样合成最终股票排名？

## 目标

理解方向调整、缺失门槛、等权平均和相关因子重复投票，并复核一只股票的综合分。

## 一、先统一方向

最终分数都约定越高越好：

```text
方向后分数 = 截面标准分 × direction
```

低波动假设的原始波动率越低越好，所以方向为-1。

## 二、手算综合分

某股票4个方向后分数：

```text
动量       1.2
反转       0.4
低波动     0.8
流动性    -0.2
```

等权平均：

```text
(1.2 + 0.4 + 0.8 - 0.2) / 4 = 0.55
```

项目还会把当日全部股票的综合原始分再次Z-score，得到最终 `factor_processed`。

## 三、缺失门槛

当前至少要有11个因子中的8个有效。少于8个，综合分设为缺失。

每个单因子每天在股票池内还必须达到80%覆盖率；否则该因子当天整截面作废。

## 四、相关因子会重复投票

`volatility_20` 与 `volatility_60` 往往相关。两者等权加入，相当于低波动主题得到两票。增加因子数量不等于增加独立信息，因此要检查 `factor_correlation.csv`。

## 五、两种综合方式

### 固定全样本诊断

配置中的11个因子按预设方向等权，便于保持固定研究口径。

### 滚动样本外综合

每折只使用训练和验证IC都为正的方向后因子，按验证IC加权，随后冻结到测试年。

## 七、实践

从 `factor_scores.parquet` 选择最新交易日的一只股票：

1. 抄下11个因子列；
2. 数有效因子是否与 `valid_factor_count` 一致；
3. 手算非缺失列均值；
4. 与 `composite_raw` 比较；
5. 解释为什么 `factor_processed` 不等于原始均值。

## 八、自测

1. 为什么波动率乘-1？
2. 有效因子少于8个怎样处理？
3. 高相关因子同时加入有什么问题？
4. 综合后为什么再次标准化？
5. 固定综合与滚动综合有何区别？

## 最低过关标准

从真实产物中手工复核一只股票的 `composite_raw`，并说清单因子列已经乘过方向。
