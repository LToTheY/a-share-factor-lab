# 第8课：回测怎样模拟真实交易

## 本课只解决一个问题

> 目标持仓怎样在下一交易日变成股数、现金、费用和净值？

## 本课目标

- 能复核一笔买卖；
- 理解先卖后买、整手和现金限制；
- 理解滑点、佣金、过户费和印花税；
- 理解停牌和涨跌停约束；
- 会读交易、持仓和权益三张表。

## 一、回测每天做什么

1. 收到上一个信号日的目标权重；
2. 在下一交易日开盘计算调仓前资产；
3. 先卖出需要减仓的股票；
4. 用释放的现金买入；
5. 不能交易的持仓继续保留；
6. 收盘按真实收盘价估值；
7. 记录现金、持仓市值和总权益。

## 二、买入股数例子

开盘前资产100万元，某股票目标5%，目标金额5万元，开盘价23元：

```text
理论股数 = 50000 / 23 ≈ 2173股
向下取整到整手 = 2100股
```

## 三、滑点和费用

默认5个基点：

```text
买入价 = 开盘价 × 1.0005
卖出价 = 开盘价 × 0.9995
```

佣金为成交额的0.03%，最低5元，另有参数化过户费。卖出还收印花税：2023-08-28前0.1%，此后0.05%。买入不收印花税。

## 四、交易受阻

- 停牌：买卖都不能做；
- 涨停：不能买；
- 跌停：不能卖。

目标要求清仓但股票跌停时，持仓不能凭空删除，必须继续留在账上。

## 五、三张表

- `trades.csv`：实际模拟成交；
- `positions.csv`：每日每只持仓的股数和市值；
- `equity.csv`：每日现金、持仓市值和总权益。

```text
equity = cash + market_value
```
