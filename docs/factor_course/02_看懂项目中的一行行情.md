# 第2课：看懂项目中的一行行情

## 本课只解决一个问题

> `baostock_daily.parquet` 中一行数据代表什么，哪些价格用于研究，哪些价格用于成交？

## 本课目标

- 能解释主键 `(trade_date, symbol)`；
- 能区分原始OHLC和后复权OHLC；
- 理解成交量、成交额和状态字段的单位与时点；
- 能从真实数据抽取一行并解释。

## 一、什么是长表

项目使用长表：一行是一只股票在一个交易日的数据。

```text
trade_date   symbol      close   amount
2026-09-16   000001.SZ   ...     ...
2026-09-16   000002.SZ   ...     ...
2026-09-17   000001.SZ   ...     ...
```

唯一身份由两列共同决定：

```text
(trade_date, symbol)
```

同一股票可以有很多日期，同一日期可以有很多股票，但同一日期同一股票不能出现两次。

## 二、股票代码为什么带交易所

只写 `000001` 容易在不同市场体系中歧义。本项目使用类似：

```text
000001.SZ
600000.SH
```

代码应作为字符串，不能转成整数，否则前导0会丢失。

## 三、两套价格

### 原始价格

```text
open, high, low, close
```

是当天真实价格尺度，用于：

- 下一开盘成交；
- 计算买多少股；
- 100股整手；
- 现金、佣金和税；
- 每日持仓市值。

### 后复权研究价格

```text
adj_open, adj_high, adj_low, adj_close
```

用于：

- 计算历史收益；
- 动量、反转、波动率；
- 未来收益标签。

## 四、为什么除权会制造假暴跌

简化例子：某股票10送10。

```text
除权前收盘：20元，持有100股，总值2000元
除权后价格：10元，持有200股，总值仍约2000元
```

只看原始价格会得到：

```text
10 / 20 - 1 = -50%
```

但投资者并没有真的亏50%。复权价格会把这个机械跳变处理成连续序列。

## 五、为什么不能用复权价买股票

复权价是研究尺度，不一定是历史上真实挂牌价格。若复权价显示5元、真实开盘价是20元，用5元算股数会买入四倍数量，现金账本完全错误。

因此必须牢记：

```text
研究收益 → adj_close
模拟成交 → open/close
```

## 六、成交量和成交额

- `volume`：股；
- `amount`：元；
- `turnover_rate`：换手率，注意数据源口径。

数据源原始单位可能不同。Tushare的成交量常以“手”、成交额以“千元”返回，进入核心表前必须转换。本项目的数据契约统一到股和元。

单位错100或1000倍时，价格因子也许不受影响，但流动性过滤、Amihud因子和容量判断会严重错误。

## 七、状态字段

重要字段包括：

- `is_st`：当日是否ST；
- `is_suspended`：当日是否停牌；
- `is_limit_up`：是否涨停受限；
- `is_limit_down`：是否跌停受限；
- `in_index`：当期是否属于指数成分；
- 对应的 `*_known`：这个状态是否真的已知。

“未知”不等于“否”。缺少ST数据时直接填 `False`，相当于武断地认为全部非ST。

## 九、检查主键是否重复

```powershell
.\.venv\Scripts\python.exe -c "import pandas as pd; x=pd.read_parquet('data/processed/baostock_daily.parquet', columns=['trade_date','symbol']); print(x.duplicated(['trade_date','symbol']).sum())"
```

预期是0。若不为0，rolling、合并、权重和回测都会重复计算。

## 十、停牌与缺失不是一回事

### 停牌

真实发生的市场状态。股票存在，但不能正常交易。

### 供应商缺口

本应有数据，却因下载或数据源原因缺失。

### 复权缺口

原始行情存在，但无法可靠得到连续复权价格。

三者不能统一前向填充。停牌可以按交易规则处理，供应商缺口需要修复或排除，复权缺口会污染收益。

## 十二、闭卷自测

1. 为什么股票代码必须是字符串？
2. 动量为什么使用 `adj_close`？
3. 买入股数为什么使用真实 `open`？
4. 未知状态为什么不能直接当作False？
5. 主键重复会造成什么后果？

## 参考答案

1. 防止前导0丢失，并保留交易所标识。
2. 消除分红送转导致的机械价格跳变。
3. 股数和现金必须按真实可成交价格计算。
4. 未知代表没有证据，False代表已经确认不是，两者含义不同。
5. 同一股票同一天会被重复计入计算、选股和回测。

## 最低过关标准

能拿出一行真实数据，逐列解释，并脱口而出：

> 复权价用于研究收益，原始价用于真实成交尺度。
