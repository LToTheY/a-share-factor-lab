# 第4课：把不同因子变成可比较分数

## 本课问题

> 动量、波动率和流动性单位完全不同，怎样放在一起比较？

## 目标

理解时间序列与横截面的区别、MAD去极值、Z-score、方向调整和中性化，并完成一次6只股票手算。

## 一、时间序列和横截面

- 时间序列：同一只股票跨很多日期，例如计算60日动量；
- 横截面：同一天比较很多股票，例如判断谁的动量更高。

rolling和shift通常按 `symbol` 分组；去极值和标准化按 `trade_date` 分组。

## 二、为什么不能直接平均原始值

动量可能在 `-0.2到0.3`，波动率可能在 `0.01到0.08`，非流动性可能是很小的科学计数。直接相加会让量纲和数值范围支配结果，而不是预测信息。

## 三、MAD去极值手算

6只股票原始值：

```text
1, 2, 3, 4, 5, 100
```

中位数3.5；绝对偏差为 `2.5,1.5,0.5,0.5,1.5,96.5`；MAD为1.5。

项目用：

```text
robust_sigma = 1.4826 × MAD = 2.2239
```

默认5倍边界，上限约 `3.5 + 5×2.2239 = 14.6195`。100被截到约14.62，但这只股票没有被删除。

## 四、Z-score

\[
z_i=(x_i-mean(x))/std(x)
\]

- `z=0`：接近当日平均；
- `z=1`：高于平均约一个标准差；
- `z=-2`：低于平均约两个标准差。

标准化后，不同因子都成为无量纲的相对分数。

## 五、方向调整

项目希望综合分“越高越好”。

- 动量假设越高越好：`direction=+1`；
- 波动率假设越低越好：`direction=-1`。

```text
用于综合的分数 = factor_processed × direction
```

方向必须在看测试结果前约定，不能看完全样本IC后随意翻转。

## 六、两个容易混淆的输出

`factor_summary.csv` 中：

- `mean_ic`：乘方向以前的处理因子IC；
- `oriented_mean_ic`：`mean_ic × configured_direction`。

`factor_scores.parquet` 中以11个因子名命名的列已经乘过方向。

## 七、中性化

若有可靠历史市值和行业，可以每天回归：

```text
因子 = 常数 + 对数市值 + 行业哑变量 + 残差
```

残差代表剔除这些暴露后的部分。当前免费数据缺少严格时点字段，所以主配置关闭中性化。错误数据做中性化比明确不做更危险。

## 九、练习

继续对 `[1,2,3,4,5,100]`：

1. 截断100；

4. 假设它是风险因子，再全部乘-1；
5. 解释乘-1后哪只股票得分最高。
