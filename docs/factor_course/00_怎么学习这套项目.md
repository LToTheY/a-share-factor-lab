# 第0课：怎么学习这套项目

## 本课目标

这节不学公式。你只需要建立正确学习方式，避免一开始就被1250行参考手册和几十个代码文件压住。

完成后，你应当知道：

- 哪些内容现在学，哪些先不学；
- “看懂”和“真正掌握”有什么区别；
- 每节课需要留下什么成果。

## 一、你现在不需要学什么

当前阶段先不学：

- LightGBM、MLP和深度学习；
- 自动调参；
- 高频交易；
- 复杂风险模型；
- Qlib配置；
- 所有工程脚本的实现细节。

先学一条最短主线：

```text
一行行情
→ 一个因子
→ 一个未来收益
→ 判断因子是否有效
→ 选股票
→ 模拟交易
→ 看样本外结果
```

这条线学会后，多因子和机器学习只是增加特征和组合方法。

## 二、“读懂”分四个层次

### 层次1：见过

你看过“RankIC”这个词，知道它是一种相关系数。

### 层次2：能解释

你能说：同一天把股票按因子和未来收益分别排名，再计算两个排名的相关性。

### 层次3：能操作

你能给5只股票手算排名，或用项目函数算出结果。

### 层次4：能判断

你能解释为什么IC为正但组合仍可能亏损，并知道下一步检查分组、换手、成本和头部股票。

本课程的目标至少是层次3，关键概念达到层次4。

## 三、每课使用“解释—修改—复现—讲述”

以动量因子为例：

1. **解释**：说清 `P(t-5)/P(t-60)-1`；
2. **修改**：把60和5换成20和5，预测变化；
3. **复现**：运行测试并和手算对照；
4. **讲述**：不用看代码，向别人解释为什么要跳过最近5日。

只读代码没有完成这个闭环。

## 四、建立学习记录

每课复制下面模板：

```markdown
# 第X课学习记录

日期：
用时：

## 我原来以为

## 我现在理解

## 本课最小例子

## 我运行的命令

## 我得到的结果

## 我仍然不懂

## 闭卷复述

## 是否过关及依据
```

“我仍然不懂”必须允许为空以外的内容出现。能准确说出不懂什么，本身就是进步。

## 五、遇到公式怎么办

按下面顺序：

1. 先把符号替换成中文；
2. 用3至5只股票的具体数字代入；
3. 再看通用公式；
4. 最后看代码怎样实现。

例如：

\[
r=P_{future}/P_{today}-1
\]

先不要背。换成：今天10元，未来11元，收益就是 `11/10-1=10%`。

## 六、本课实践

在学习记录里写下：

1. 你目前对Python、统计和金融分别学到什么程度；
2. 你最害怕本项目中的哪三个词；
3. 你希望最终能够独立完成什么；
4. 每周实际可以完成几节45分钟课程。

## 七、闭卷自测

1. 为什么不能把“读完文档”当成学会？
2. 解释—修改—复现—讲述分别是什么？
3. 遇到公式看不懂时，第一步做什么？

## 参考答案

1. 因为读完只证明接触过，不能证明能解释、计算、修改和判断。
2. 先理解逻辑，再做一个小变化，实际运行复现，最后脱离原文说清楚。
3. 把符号换成中文和具体数字，先理解它在算什么。

## 最低过关标准

完成学习记录模板，并能用一句话说出本课程主线：

> 用当时可见的数据计算因子，检验它能否预测未来收益，再按可执行规则模拟交易并做样本外验证。
