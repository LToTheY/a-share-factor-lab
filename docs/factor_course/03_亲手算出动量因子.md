# 第3课：亲手算出动量因子

## 本课只解决一个问题

> `momentum_60_5` 到底用了哪些日期、为什么这样写、代码怎样保证不串股票？

## 本课目标

- 手算 `momentum_60_5`；
- 理解lookback和skip；
- 理解 `groupby + shift`；
- 能修改为 `momentum_20_5` 并预测结果；
- 知道因子前期NaN为什么合理。

## 一、先把名字拆开

```text
momentum_60_5
         │  └─ 跳过最近5个交易日
         └──── 从60个交易日前开始观察
```

公式：

\[
MOM_{60,5}(t)=\frac{P_{t-5}}{P_{t-60}}-1
\]

它并不是“过去60日收益”，而是从 `t-60` 到 `t-5` 的收益。

## 二、用数字手算

假设某股票：

```text
t-60 后复权收盘价 = 10元
t-5  后复权收盘价 = 13元
t    后复权收盘价 = 12元
```

则：

```text
momentum_60_5 = 13 / 10 - 1 = 0.30 = 30%
```

注意当前12元没有进入公式。最近5日从13元跌到12元被故意跳过。

## 三、为什么跳过最近5日

研究假设是：

- 较长时期趋势可能延续；
- 最近几日可能有短期反转或微观结构噪声；
- 跳过近期可以尽量分离两种效应。

这只是待验证假设，不是金融定律。项目同时保留 `reversal_5`，正是为了观察短期反转。

## 四、代码逐句拆解

打开：

```text
src/quant_lab/factors/library.py
```

核心函数：

```python
def momentum(frame, lookback=60, skip=5):
    if lookback <= skip or skip < 0:
        raise ValueError("Require lookback > skip >= 0")
    require_columns(frame, ["symbol", "close"])
    price = _adjusted_close(frame)
    grouped = price.groupby(frame["symbol"], sort=False)
    return grouped.shift(skip) / grouped.shift(lookback) - 1.0
```

逐句解释：

1. `lookback > skip`：起点必须比终点更早；
2. 检查至少有股票代码和收盘价；
3. 优先取 `adj_close`；
4. 按股票分组；
5. 分别取每只股票第5行前和第60行前的价格；
6. 两者相除减1。

## 五、`shift(5)` 到底是什么

对一只股票：

```text
日期        price    shift(1)
周一        10       NaN
周二        11       10
周三        12       11
```

`shift(1)` 把昨天的值放到今天这一行。`shift(5)` 就把5个交易记录前的值放到今天。

这里的“5”是该股票的5条历史记录，不是5个自然日。

## 六、为什么必须分组

长表里可能是：

```text
A股票最后一天
B股票第一天
```

不分组时，B股票的历史可能错误引用A股票。按 `symbol` 分组后，每只股票独立移动。

项目测试故意构造：

- A价格为 `1, 2, 3...`；
- B价格为 `1000, 2000, 3000...`。

两者价格尺度差1000倍，但相对走势相同，所以动量必须相同。

## 七、为什么前60行是NaN

第20个交易日没有 `t-60` 价格，无法计算60日动量。正确结果就是缺失，而不是填0。

填0相当于声称“动量为零”，这是一条虚假的经济信息。

最长因子需要历史预热，所以项目从2015年开始准备数据，正式评价从2016年开始。

## 九、自己构造最小例子

```python
import numpy as np
import pandas as pd

from quant_lab.factors.library import compute_factor

dates = pd.bdate_range("2025-01-01", periods=70)
frame = pd.DataFrame(
    {
        "trade_date": dates,
        "symbol": "TEST",
        "close": np.arange(1.0, 71.0),
        "adj_factor": 1.0,
    }
)

result = compute_factor(frame, "momentum_60_5")
print(result.tail())
```

第70行对应价格70：

- `t-5` 对应65；
- `t-60` 对应10；
- 因子应为 `65/10-1=5.5`。

这也是现有单元测试的核心思路。

## 十、对比三个动量因子

| 因子 | 起点 | 终点 | 更关注什么 |
|---|---:|---:|---|
| `momentum_20_5` | t-20 | t-5 | 较短趋势 |
| `momentum_60_5` | t-60 | t-5 | 中期趋势 |
| `momentum_120_20` | t-120 | t-20 | 更长期趋势，跳过近一个月 |

窗口越长不等于越好。长窗口更平滑，但反应更慢、预热更长。

## 十二、本课常见错误

### 错误1：把60理解成自然日

代码按该股票的交易记录移动60行，近似60个交易日。

### 错误2：用原始收盘价计算跨除权收益

会把分红送转误认为价格变化。

### 错误3：因子NaN就填0

缺历史不代表动量为0。

### 错误4：全表直接shift

会发生跨股票串值。
