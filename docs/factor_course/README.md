# A股因子研究入门课：结合本项目逐课学习

这套课程不是让你一次读完一本长手册，而是每次只解决一个问题。

原来的 `docs/FACTOR_RESEARCH_TUTORIAL.md` 保留作参考手册：忘记某个公式时查它。学习时以本目录的逐课笔记为主。

## 课程适合谁

默认你会最基础的Python语法，但不要求你已经理解：

- 因子、标签、股票池分别是什么；
- RankIC、截面标准化和滚动回测；
- 复权、未来函数、幸存者偏差；
- 信号怎样变成真实交易。

如果你看见公式容易紧张，可以先只读每课的“白话版”和例子，再回头看公式。

## 每课固定结构

每课约45分钟：

1. 5分钟：回忆上一课；
2. 15分钟：读白话解释和例子；
3. 15分钟：结合本项目操作；
4. 10分钟：闭卷回答、自测和记录。

每课都有“最低过关标准”。没有过关就不要硬赶进度，先把本课练习缩小再做一次。

## 学习时只开这些窗口

建议同时打开：

1. 当前课程笔记；
2. 课程指定的一个代码文件；
3. PowerShell终端；
4. 你自己的学习记录。

不要同时打开十几个源文件。每一课只读指定函数。
