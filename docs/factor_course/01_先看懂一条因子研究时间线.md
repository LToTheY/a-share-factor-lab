# 第1课：先看懂一条因子研究时间线

## 本课只解决一个问题

> 日期 `t` 的数据什么时候知道，它预测哪段未来，又在什么时候交易？

这是整个因子回测最重要的一课。时间顺序错误，后面所有高收益都没有意义。

## 本课目标

完成后，你能够：

- 区分特征、信号、标签和成交；
- 解释为什么不能用当天收盘信号按当天收盘价成交；
- 在项目交易文件里验证成交日晚于信号日；
- 解释5日标签为什么需要5日隔离带。

## 一、先用生活例子理解

假设学校每天18:00公布全班当天跑步成绩。

- 18:00以前，你不知道完整排名；
- 18:00公布后，你可以根据排名制定明天的训练计划；
- 你不能说自己在当天17:00就已经根据18:00的排名采取行动。

股票收盘数据也一样。只有收盘后，你才知道完整的收盘价、成交额和当日状态。

## 二、项目中的四个时间概念

### 1. 特征数据

日期 `t` 收盘后可见的历史价格、成交量和成交额。

### 2. 因子/信号

使用截至 `t` 日的数据计算出的股票分数和排名。

### 3. 成交

项目默认在下一交易日 `t+1` 的开盘尝试执行，而不是在 `t` 日收盘成交。

### 4. 标签

日期 `t` 的未来5日标签：

\[
P_{t+5}/P_t-1
\]

它要到 `t+5` 收盘后才完整，只用于回头评价日期 `t` 的因子。

## 三、画出一条真实时间线

假设：

- 9月10日是信号日；
- 9月11日是下一交易日；
- 9月17日是向后数第5个交易日。

```text
9月10日盘中
    还不知道当天完整收盘数据

    得到adj_close、amount等
    计算因子
    形成股票排名和目标权重

    回测尝试按open成交
    还要检查停牌、涨停、跌停和现金

9月17日收盘后
    9月10日对应的未来5日收益标签才完整
    标签只用于研究评价
```

## 四、什么是未来函数

未来函数是日期 `t` 的决策使用了当时不可能知道的信息。

常见错误：

1. 用 `t+5` 的价格计算因子；
2. 用当天收盘后才能得到的因子，却按当天收盘价成交；
3. 用未来年份结果决定过去因子方向；
4. 用今天的指数成分股回填十年前；
5. 财报按报告期末使用，而不是等到公告日。

未来函数不一定写成明显的 `shift(-5)`，也可能藏在数据填充、股票池或参数选择里。

## 五、结合项目看代码

本课只看一个函数：

```text
src/quant_lab/backtest/engine.py
```

找到 `_execution_schedule()`：

```python
position = trading_dates.searchsorted(signal_date, side="right")
```

`side="right"` 的意思是寻找严格晚于信号日的第一个交易日。不是当天，也不是简单加一个自然日。

为什么不能直接 `signal_date + 1天`？因为下一天可能是周末或休市日。

## 八、为什么要留5日隔离带

假设训练期截至2020-12-31，而标签是未来5日收益。

2020-12-31这条训练记录的标签需要2021年价格。若2021年是验证期，训练数据就偷看了验证期。

所以项目从训练期尾部删除5个交易日；验证期尾部也删除5日，避免验证标签进入测试期。

```text
训练数据 ─── [删5日]
验证数据 ─── [删5日]
测试数据
```

隔离带长度至少应覆盖标签长度。若改成未来20日标签，仍只隔离5天就不够。

## 九、本课常见误解

### 误解1：收盘价是公开数据，所以可以按同一收盘价买

你在知道最终收盘价时，连续竞价已经结束。研究中必须假设下一次可执行机会。

### 误解2：未来收益标签出现在同一张表里，所以模型可以使用

同表只是便于离线评价。代码职责和时间含义不同，标签不能进入信号。

### 误解3：下一交易日就是第二天

周五下一交易日通常是周一；节假日可能隔更久。

## 十一、闭卷自测

1. 为什么 `t` 日收盘形成的信号不能按 `t` 日收盘成交？
2. 标签和因子最根本的区别是什么？
3. 为什么用交易日历找下一日，而不是日期加1？
4. 未来5日标签为什么需要5日隔离带？
5. 在哪个文件能直接检查信号日和成交日？

## 参考答案

1. 因为只有收盘后才知道形成信号所需的完整数据，此时该收盘成交机会已经过去。
2. 因子只使用当时及过去可见信息；标签描述未来结果，只用于评价。
3. 周末和节假日不是交易日。
4. 防止训练期尾部标签使用验证期价格，或验证期标签使用测试期价格。
5. `trades.csv`，比较 `signal_date` 和 `trade_date`。

## 最低过关标准

不看笔记，用一分钟完整说出：

> t日收盘后用截至t日的数据计算因子和排名，t+1开盘尝试交易，t+5价格只用于后来评价；训练和验证尾部各隔离5个交易日，避免标签跨区间泄漏。
